# 06 机器设计

本模组共 **29 台机器**（T1 作坊 10 台、T2 机械化 9 台、T3 化工 7 台、T4 生物/精细 3 台），覆盖 05 中的全部 96 项工艺。机器与手工工具共用 19 种配方类型（R01–R19），同一条配方在不同档次的设备上速率、纯度、产率不同；功能相近的机器已合并，差异改为模式或模块。合并方案、配方类型、程序架构、槽位与界面见 [../machines/](../machines/README.md)。另有 9 种 T0 手工工具（H01–H09）与 6 种世界交互（H10–H15），见 07。

## 通用约定

- **动力**：T1 用燃料（煤、木炭、木柴）加热，手摇柄驱动（水车不做，以后接机械动力的应力，2026-11-10 定）；T2 起统一用 FE。T2 是否额外支持“蒸汽 / 机械动力（Create 应力）”作为动力输入，列为待定问题（11）。
- **热量**：加热类机器显示温度档位（常温 / 加热 / 高温 / 冷却 / 冷冻），配方要求档位而不是具体温度。
- **流体**：所有液体、气体都按 Forge 流体处理（CO2、SO2、NH3、H2 等为气态流体），以便 AE2、管道、储罐直接兼容（见 10）。
- **能力接口**：每台机器（多方块为其仓口）对外暴露物品、流体、能量能力，按面配置输入、输出；满足 AE2 样板供应器直接推送。各版本节点的能力接口不同，由 `platform` 适配（../machines/02）。
- **原版设备**：营火、熔炉、烟熏炉（T0）与高炉（T1）执行单输入单输出的干燥、烟熏、窑炉配方，不计入 29 台机器（../machines/01 第 5 节）。
- **纯度**：由原料和工序决定（来源、除杂、保持、劣化），设备档次只加成：比配方的基准档次每高一档，剩余杂质再去掉 25%；同一设备、同一配方、同一输入纯度结果唯一（见 10 第 2.1 节）。装规范化模块的设备把产出降到所在档位的下限（../machines/01 第 1.2 节）。

#### T1 作坊：操作与实现规格（I14）

> 2026-11-10 草案经用户确认（2026-11-10）：不做水车，人力用手摇柄，以后与机械动力（Create）的应力联动（I25）；多方块固定 3 × 3 × 3 空心；冷凝器是单独方块，装在蒸馏甑顶面；07 手工配方补机器时长。实现后复审（2026-11-10）：浸提桶加过滤、熬煮灶加 R04 与 R06；曲房每 40 tick 耗水；缺条件暂停；仓口合成；多方块按方向要求仓口、控制器不收发物品；名称、描述、合成摆法与占位贴图通过。数值、合成配方为游戏设定。

共同：单方块机器右键打开界面，槽位按 ../machines/03 §3，T1 储罐 4,000 mB，没有升级槽；模式在界面右上角切换。模式名加入工艺条件词表的新类别“模式”（`mode`），配方用 `"mode": "<模式>"` 指定。

**人力（M01、M02）**

- 新动力方式“人力”：机器有一个动力计时，只在有动力时运转；动力用完就停，进度保留。
- 手摇柄（新方块）：装在 M01 或 M02 的顶面（只能放在这两台机器上，机器拆掉时掉落），空手右键摇一次加 20 tick 动力，最多存 100 tick；速度为配方时长 × 1。
- 水车不做（2026-11-10 定）；以后 M01、M02 接机械动力（Create）的应力作为动力，在 I25 实现。接法（2026-11-11，用户确认）：顶面装“传动接口”方块代替手摇柄，接机械动力的传动轴；32 RPM 等于手摇速度，转速越高越快，最快 ×4；每 RPM 耗 4 应力（同机械动力石磨）；只在装了机械动力时注册。

**缺条件时暂停**（2026-11-10 定）：正在做的配方只因条件暂时不满足（晾晒时天黑、拿走模块、切换模式）而不能继续时，进度保留，条件恢复后接着做；换了原料或换成别的配方才清零。07 的被动设备同样处理（晒盐池只在下雨时清零进度）。

**M06 曲房的温湿度**：控制器燃料槽的燃料（火盆）点着时为“温暖”，燃料只在运转时按熔炉规则点燃，没有燃料也能运转；流体输入有水时为“湿润”（运转时每 40 tick 耗水 10 mB，2026-11-10 定）；两者都满足为“温湿度达标”，带 `purity_range` 的配方（红曲米，I18）在达标时取区间上半，否则取整个区间。温湿度不影响能否运转。

**多方块（M06、M07、M10）**：固定 3 × 3 × 3（2026-11-10 定），中心一格空，控制器在正面中层正中；外壳各用一种新方块（曲房墙、窑砖、烘房墙），外壳位置可换成物品仓、流体仓；物品仓也接受燃料：能烧又不是本机器配方原料的物品放进燃料槽。可变尺寸暂不做。

**仓口与控制器**（2026-11-10 定，所有多方块）：机器槽位里有的每个方向，都要有一个设成该方向的仓口才能成形——有物品输入、催化剂或燃料槽要“输入”物品仓，有物品产物要“输出”物品仓，有输入、输出储罐各要“输入”“输出”流体仓，用 FE 要能量仓；改仓口方向会重新检查结构，结构页列出缺的仓口（如曲房要输入物品仓、输出物品仓、输入流体仓；土窑、烘房要输入物品仓、输出物品仓、输出流体仓）。控制器界面不显示槽位和储罐，不能放入、取出，只显示状态（燃烧、进度、产物纯度）、信息与设置（模式、红石）；物品、催化剂、燃料在物品仓界面放取，液体与排放开关在流体仓界面。

**M29**：

- 结构：3 × 3 截面：底层全是外壳（控制器在正面正中）、罐体 1–4 层（四周外壳、中心不限）、顶层，共 3–6 层；外壳“无菌罐壁”，可换成仓口或进气口

**M30 专用界面**（2026-11-11 定）：

- 操作：用模式按钮切换，界面中部是培养皿（平板）和四个按钮“接种”“鉴定”“挑取”“弃去”。平板分离、纯化、诱变、基因重组走“接种 → 培养 → 鉴定（可选）→ 挑取”；扩培不挑菌落，同普通机器自动运转（可自动化）
- 槽位（2026-11-11，用户补充）：四个输入槽依次只收标签 `culture_bench/samples`（样本或菌种）、`culture_bench/media`（培养基）、`culture_bench/donors`（供体样本）、`culture_bench/vectors`（表达载体）中的物品；配方的原料必须在对应标签里，数据生成检查（08 §标签体系）
- 接种：放好样本或菌种与培养基（琼脂），基因重组另放供体样本与表达载体，点“接种”：按当前操作找配方，消耗输入，开始培养（配方时长，耗电）；产物的纯度在接种时按配方规则算好
- 平板：培养完成后长出 4 个菌落（配方 `plate.colonies`），每个菌落按配方产物的权重抽取（`plate.weights`，省略为都是 1）；纯化平板（`plate.by_purity`）每个菌落是目标菌（第一个产物）的概率等于输入菌种的纯度，否则是第二个产物（杂菌）
- 外观：每种物品的菌落颜色（16 种）与色块图案（8 种）固定，由物品 ID 的散列决定，材料表里的菌种互不相同（冲突时按 ID 顺序取下一个），在任何平板上都一样；未鉴定时悬停只显示“未鉴定菌落”
- 鉴定：点“鉴定”，用 200 tick、40 FE/t（再乘档次与升级），之后悬停显示菌种名
- 挑取：点选一个菌落再点“挑取”，得到该产物放进任一个放得下的产物槽，其余菌落丢弃；不鉴定也能挑（盲选）；“弃去”丢掉整个平板。平板一直保留到挑取或弃去，期间不能接种，扩培也暂停
- 配方：R18，`mode` 写操作名；平板操作写 `"plate": { "colonies": 4, "weights": [3, 1] }` 或 `"plate": { "by_purity": true }`；扩培不写 `plate`
- 状态：等待接种 / 培养中 / 平板待挑取 / 鉴定中

## 他模组机器参与

原则：**他模组机器只承担物理工序和成品烹饪**，输入可带纯度门槛（实现要点 2），输出纯度是生成配方时算好的固定值（10 第 7 节）；化学反应、精制、无菌发酵留在本模组机器里，保证纯度体系和科技线不被绕过。参与方式是由本模组通过数据生成（datagen）往对方的配方类型里注册等价配方，对方机器本身不改。

实现要点：

1. **纯度**：他模组配方的输出写死为固定纯度（多数机器支持在结果 JSON 中带 NBT，需逐个核实）。取值按 10 第 7 节：农夫乐事、机械动力按 T1，热力、通用机械、气动工艺、核电工艺按 T2，输入取门槛值计算。
2. **纯度门槛输入**：用本模组的纯度原料类型 `foodindustrial:purity`（10 第 4 节）。对方配方若通过标准 `Ingredient` 解析输入（机械动力、农夫乐事通常如此），可直接使用；不支持的机器只开放无纯度要求的原料工序。
3. **化学品（气体）**：通用机械的气体走 Mekanism Chemical 体系，与 Forge 流体不通用。本模组的气体一律用 Forge 流体；如需进入通用机械机器，只在 Rotary Condensentrator 这类转换处对接，不把核心链路建在 Mekanism 气体上。
4. **标签输入**：注册进他模组配方类型的配方，输入同样写本模组标签（见 08），不写具体物品。
5. **开关**：每个联动模组一组配置项（启用 / 设备档次），并且只在对方模组加载时注册（`ModList.isLoaded`）。
6. 上表的机器名称以各模组 1.20.1 版本的英文名为准，具体配方类型 ID 在实现前逐个核对。
