# 07 人力制备（T0 手工与世界交互）

T0 阶段用 **9 种手工工具 + 6 种世界交互 + 原版的营火、熔炉、烟熏炉**，做出第一批中 10 种产品（食醋、酸浆、粗碱、粗钾碱、苦卤、半水硫酸钙、琼脂、糖色、硝酸钾、硫熏食品）和第二、三批中 12 种产品的低档品。手工产物的纯度由原料和工序决定：来源工序取现实中同类土法产品的含量，之后的工序按去除杂质的比例提高纯度；同一工序、同一原料只产出同一结果（规则见 10 第 2.1 节）。手工工具与机器共用配方类型：同一条配方写一次，研钵、石磨、粉碎机都能执行，只是速率、纯度加成、产率不同（../machines/01）。

## 设计要点

1. **每个手工做法都有真实原型**：海藻灰、草木灰淋灰、晒盐与苦卤、卤水点豆腐、寒天冻融、炒糖色、硝土熬硝、燃硫熏蒸、自然接种发酵，都是人类历史上实际使用过的方法。
2. **环境参与**：日照、降雨、群系温度、牲畜、季节决定手工工序能否进行、耗时和产量，让开局玩法和地图探索挂钩；环境不改变纯度。
3. **原料与工序决定纯度**：每道手工工序是来源、除杂、保持、劣化之一（10 第 2.1 节）。来源工序的数值取自现实中同类土法产品（见“数值依据”）；H03 锅上的重结晶去除 50% 的杂质，可反复做，每次数量减半；每条手工精制配方按现实工艺写手工上限 `t0_max`，多数为粗制或精制下限，到上限后再做只减量。灰、浸液、凝胶等中间物属 K0，有数据的显示含量，没有的不带纯度。
4. **全部在 JEI 可查**：世界交互也注册成 JEI 配方类别，显示条件（群系、露天、天气、时间）和纯度规则。

## 操作与实现规格（I12）

### 手工工具：H01 研钵、H02 筛子、H02 布袋（物品）

已定（2026-11-10）：这三件是物品，在物品栏里用“叠放”操作使用，不放置。

| 工具 | 配方类型 | 能力 | 合成（拟定） |
| --- | --- | --- | --- |
| H01 研钵 | R01 研磨 | — | 石头或方解石 ×3 + 木棍 ×1（`  K` / `S S` / ` S `） |
| H02 筛子 | R03 固液分离 | 过滤 | 木棍 ×4 + 线 ×3（`K K` / `TTT` / `K K`） |
| H02 布袋 | R02 压榨、R03 固液分离 | 过滤 | 线 ×2 + 任意羊毛 ×1（`T T` / ` W `） |

1. **操作**：工具拿在光标上，右键点原料所在的格；或原料拿在光标上，右键点工具所在的格（已定）。每点一次推进一步，`manual.actions` 步完成一次。左键照原版。
2. **进度**记在工具上，悬停显示“研磨 3/8”；换原料或换配方时清零。
3. **完成**：按配方数量消耗原料，产物放进背包，放不下的掉在玩家脚下。
4. **流体**：装着流体的桶算作原料，一桶 1,000 mB；流体产物装回同一个桶（只能有一种、正好 1,000 mB），没有流体产物时还回空桶。
5. 手工工具只做“一个物品输入或一桶流体输入”的配方，数据生成检查。
6. 不耗损。

### H06 晒盐池

已定（2026-11-10）：单个方块，相邻的晒盐池互相连接。

- 水平相邻的晒盐池连成一片：池沿在相邻处不画；往任意一格倒海水，按格平均分到这一片；用桶取苦卤从这一片各格取；空手 Shift + 右键取出这一片所有格的盐。
- 每格各自计时出盐。条件：露天、晴天、白天；炎热群系耗时减半；下雨时这一格的进度清零（07 苦卤行）。

### 原地转化与失败产物

- 锅、陶坛、晾晒架、曲盘、晒盐池里的东西**原地转化**：配方的产物放回同一处，输入与产物共用格子和储罐。储罐只能装一种流体：流体产物与储罐里剩下的流体不同种时，这条配方不进行。
- 失败产物写成**接着发生的配方**：产物留在设备里，满足条件就继续转化。糖色在铁锅里继续搅拌 → 焦糖渣；熟石膏在锅里继续干炒 → 死烧石膏；发芽的小麦在曲盘上超过 4 天 → 徒长麦芽；晾晒架上的姜黄淋雨 → 霉变姜黄。
- 已定（2026-11-10）：原地转化，失败产物是接着发生的配方。
- 同一内容有多条配方可用时，取条件最多的一条（催化剂也算条件）；一样多时取原料多的一条（2026-11-11 补），再一样按配方 ID 排序。例：蒸米在遮光的丛林里得红曲霉，在遮光的其他群系得米曲霉，不遮光得杂菌；加老卤的酸浆配方比不加的快。

设备每批按所在位置计算环境能力：

| 能力 | 判定 |
| --- | --- |

| 淋雨（新增 `rain`） | 露天且这一格正在下雨 |
| 白天（新增 `daytime`） | 一天中的 0–12,000 tick |

### H11 硝土生成（W01）

已定（2026-11-10）：泥土、砂土（原版的 Coarse Dirt）只要不露天就有概率变成硝土，由两种方式触发：

1. 让泥土、砂土参与原版随机刻（platform 中三个节点各加一处改动）；每次随机刻概率 1%（按原版随机刻速度，一格平均约 1.9 小时转化）。
2. 牲畜带动：每只牲畜（实体标签 `foodindustrial:livestock`：牛、羊、猪、鸡、马、山羊等）每分钟随机检查脚下附近一格（水平 4 格内、低一格），满足条件时概率 10%。牛棚、羊圈加顶后地面会较快变成硝土。

### H12 寒冷冻融、H14 冷置析酒石

- H12：晾晒架上的石花菜冻，寒冷群系、露天，96,000 tick（4 个昼夜）后成为条状琼脂（2 → 1）。不在寒冷群系不进行。
- H14：本模组木桶罐装着葡萄酒，在寒冷群系或与冰、浮冰、蓝冰相邻时，每 72,000 tick（3 天）桶壁结出 1 份酒石，最多积 4 份；寒冷群系耗时减半；葡萄酒不消耗。手持刀右键木桶罐刮下酒石。
