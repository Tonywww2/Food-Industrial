# 05 工艺清单

从 04 的全部路线中归纳出第一批的 **56 项工艺**（P01–P56），第二、三批（13、14）又新增 23 项（P57–P79），共 **79 项**，分为机械处理、分离纯化、热处理、化学反应、生物工艺五类，新增工艺单列在 F 节。每项工艺都至少有一台机器（M，见 06）完成；能手工完成的同时列出手工工具（H，见 07）。

“用于”一栏的数字是添加剂编号：1–30 见 03，31–78 见 13，79–139 见 14；“基”表示 04 末尾的共用中间体。A–E 节的“用于”只列第一批，第二、三批对已有工艺的使用见 13、14 的路线表。每项工艺所属的配方类型（R01–R19）见 [../machines/01](../machines/01-recipe-types.md) 第 2 节；“手工”“机器”两栏列出的设备共用该配方类型，按档次区分速率、纯度和产率。

## 工艺条件（游戏参数）

实现时每条配方除输入输出外，还需要声明以下条件中的若干项；JEI 页面需全部显示（见 10）。

| 条件 | 取值形式 | 例 |
| --- | --- | --- |
| 温度 | 档位：常温 / 加热 / 高温 / 冷却 / 冷冻 | 甜菜红浓缩须“真空 + 加热”，不可“高温” |
| 压力 | 常压 / 加压 / 高压 / 真空 | 加氢须“高压” |
| 气氛 | 空气 / 隔绝空气 / 惰性（N2）/ 指定气体输入 | 干馏须隔绝空气；甘油解须 N2 |
| 无菌 | 是 / 否 | T4 发酵须无菌，否则可能染菌：该批次减产或报废，纯度不变 |
| 环境 | 群系温度、露天、日照、降雨 | 晒盐须露天、晴天；冻融须寒冷群系 |
| 时间 | tick | — |
| 能量 | FE/t（T2+），燃料（T1） | — |
| 催化剂 / 菌种 | 放在机器专用槽，不消耗或按机器内部计数消耗（不改物品 NBT，见 10） | 镍催化剂、醋酸菌种 |
