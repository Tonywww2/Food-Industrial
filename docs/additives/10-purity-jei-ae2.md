# 10 纯度、标签匹配、JEI 与 AE2 实现约束

这一章把开发补充的要求落成可执行的规则：**纯度是目标物质的湿基质量分数，存为 byte（两端对数刻度，−128 = 0%，127 = 100%）**；**纯度由原料和工艺决定：来源工序给出初始纯度，之后每道工序按“去除了多少比例的杂质”提高纯度，设备档次只做加成**；**劣质、粗制、精制、食品级、实验室级五档的界限按物料类别规定，单个物料可按自己的标准覆盖**；**所有配方输入一律按标签匹配，纯度门槛由新的原料类型 `foodindustrial:purity` 表达**；**所有物品、原料、配方在 JEI 可见**；**全部机器能被 AE2 样板自动化驱动**。同一配方、同一设备、同一输入纯度只得到同一结果，只有红曲米保留随机。

## 1 纯度数据

### 1.1 定义

**纯度 = 目标物质在这件物品（或这份流体）中的质量分数，按湿基计**：水、溶剂和其他物质都算杂质。食醋中的乙酸约 4%、饱和食盐水中的氯化钠约 26%，都按这个口径表示。

- 带纯度的是 09 与 08 §C 中分类为化学品、菌种的物料（“分类”一栏）。催化剂不带纯度；作物、矿石、海水和 08 §C 中分类为“原料”的副产与天然原料（葡萄酒、乳清、大豆毛油、乳胶、番茄皮渣、啤酒酵母、鱼肝）不带纯度（2026-11-04 定）。
- **按现实逻辑不带纯度的物料**（2026-11-05 定）：现实中不按某一物质的质量分数分档的物料不带纯度，物品不写 `Purity`，配方对它们不设门槛，它们也不参与起点纯度：
  1. 酶制剂与酶源：全部酶（08 分类为“酶”，含 94–106、374–423、溶菌酶 346）、麦芽、大麦麦芽、木瓜乳汁、无花果乳汁、胰脏浸提液。现实按酶活计价；路线中的粗酶与精制酶是同一物品，精制步骤只改变产量与用途说明。
  2. 公用介质：蒸馏水（`distilled_water`，品质看电导率），与原版水一样不带纯度。
  3. 多组分混合物：不是单一分子组成、使用时整体一起用的物料：原油、煤焦油、木焦油、减压馏分油、脱蜡油、制浆废液、苦卤、硝水、碱液、钾碱液、海藻灰、草木灰、高钛渣、磷炉渣、松脂、松香、颗粒紫胶、紫胶洗色水、万寿菊油树脂、天然油脂（植物油、硬化油、动物脂、椰子油、棕榈油、蓖麻油、鱼肝油、羊毛脂）、脂肪酸混合物、聚甘油、聚蓖麻醇酸、木质素、发酵液、液化淀粉液、环状糊精包合物湿饼（09 纯度类别写“—”）。只含单一目标物质的溶液仍为 K0，显示含量（饱和食盐水、硫酸氧钛溶液等）；GB 2760 中按某一成分计含量的添加剂（天然色素、乳化剂、胶类等）照常带纯度。 第五批香料中的精油、浸膏、净油、酊、油树脂、香脂、萜烯馏分、反应香精、烟熏液也属此类（2026-11-11）。
  4. 菌种保留纯度（目标菌所占比例），M30 的分离纯化依赖它。
- **按有效成分含量计价的提取物带纯度**（2026-11-11 定，11 问题 31）：色素、甜味剂、皂苷等天然提取物（皂树皮提取物、纯化甜菊糖苷、柚皮苷等）按主成分含量计，属 K5；与上条“整体使用的混合物”区分。辣椒油树脂整体使用，按不带纯度的混合物处理（2026-11-12，11 问题 42）。石蜡与微晶蜡统一按 K7（蜡），不再列入不带纯度的混合物。
- 成品食物不带纯度。复配产品（泡打粉、胶基、腌制剂等）带纯度，属 K12：配方要求全部组分达到各自的食品级（与 GB 26687 一致：各组分须符合各自的标准）；产物纯度由配方的纯度规则和执行设备决定，不由组分纯度推算（2026-11-05 定）。
- 纯度由**原料和工艺**决定，不由阶段决定：来源工序给出初始纯度，后续工序按去除杂质的比例提高纯度；设备档次只在此基础上加成（第 2 节）。

### 1.2 存储与刻度

- 物品：`ItemStack` 根标签下的 byte `Purity`；流体：`FluidStack` 标签下同名 byte（1.20.1 节点）。1.21.1 与 26.1.2 节点为 byte 型数据组件 `foodindustrial:purity`，由 `platform.purity` 读写，取值规则相同。
- **两端对数刻度**：b = −128 表示 0%，b = 127 表示 100%；其余取值 −127 ≤ b ≤ 126 时，纯度 p = 1 / (1 + 10^(−b / 25.4))。低纯度段和高纯度段都精细，中间段每格约 2 个百分点。
- 反算：b = 25.4 × log10(p / (1 − p))，再按下面的取整规则落到整数并限制在 −128…127：
  - **配方或数据里写定的数值**（来源纯度、档位界限、门槛、外部规则）**向上取整**：取满足 p(b) ≥ 所写数值的最小 b；
  - **计算得到的结果**（除杂、加成、加权平均）**向下取整**：取满足 p(b) ≤ 计算值的最大 b。
- 确定性：换算只用预先算好的 256 项对照表（b → p，双精度，用 `StrictMath` 生成）；反算在表上二分查找，不现场求对数。三个节点、所有平台结果一致。
- 配方与数据包 JSON 中的纯度一律写百分数（`83`、`3.5`、`99.8`），小数位数不超过显示规则在该区间的位数；去除比例、损失比例同样写百分数。
- 显示：按文本规范第 1 节第 6 条向下截断，显示值不高于实际值；由于上一条的位数限制，显示值与档位始终一致。

| b | 纯度（显示） | b | 纯度（显示） |
| --- | --- | --- | --- |
| −128 | 0% | 25 | 90.6% |
| −127 | <0.01% | 33 | 95.2% |
| −76 | 0.10% | 39 | 97.1% |
| −51 | 0.97% | 43 | 98.0% |
| −32 | 5.2% | 51 | 99.0% |
| −24 | 10% | 59 | 99.5% |
| −15 | 20% | 69 | 99.8% |
| 0 | 50% | 77 | 99.90% |

除杂按质量计算（第 2.1 节），在这个刻度上恰好是平移：去除一半杂质前进约 7.6 格，去除九成前进 25.4 格，与起点纯度无关（向下取整前）。

### 1.3 档位

五个档位：劣质、粗制、精制、食品级、实验室级。**界限按物料类别分别规定**（第 1.4 节），个别物料可按自己的国标或行业标准覆盖（第 1.5 节）。判定只看纯度：纯度 ≥ 某档下限即属于该档，低于粗制下限为劣质。

- 配方门槛写档位名时，按被检测物料的界限换算成 b；也可直接写百分比（第 4 节）。
- K0 原料与中间物不分档：物料数据写了 `source_purity` 的才带纯度，Tooltip 显示“含量 7.3%”；没写的不带纯度。
- Tooltip 显示“精制（96.3%）”（档位名在前，2026-11-04 定），只有这一行按档位着色；物品名称颜色不变（文本规范 3.1）。

| 酒石酸铁（溶液，以铁计） | `ferric_tartrate` | 0.8% | 1.7% | 2.8% | 不适用 | 以 Fe 计：干基 Fe ≥8.0%、水分 ≥65.0%（GB 1886.381-2024），8.0% × 0.35 = 2.8% |
| 亚硫酸氢钠（溶液） | `sodium_bisulfite` | 10% | 20% | 32% | 不适用 | GB 25590-2010 只管固体；溶液取欧盟 E 222 水溶液 ≥32%（2008/84/EC） |

色价类色素的粗制、精制为游戏设定；实验室级 90% 指可作分析标准品的纯色素，也是游戏设定（2026-11-05 定）。第四批补的覆盖（铝色淀起各行，2026-11-05）：食品级取自所列标准，粗制、精制为游戏设定（约为食品级的 30%、60%），这些物料不设实验室级。

### 1.6 外部物品、缺标签物品与外部纯度规则

- **配方检测到非本模组物品**（原版或他模组，例如原版的糖）时，按较低纯度处理（2026-11-04 定，原为粗制）：**外部默认值 = 该物料粗制下限的杂质加倍**，p = c ÷ (2 − c)，c 为粗制下限在刻度上的值，结果向下取整，一定落在劣质（刻度上约比粗制下限低 7.6 格）。没有粗制档的物料用最低一档的下限计算。例：糖（K2，粗制 85%）→ 74%；盐（粗制 90%）→ 82%；乙酸（最低档食品级 3.5%）→ 1.8%。
- **本模组物品缺少 `Purity`**（/give、旧存档、他人数据包的战利品、从世界取回的桶）时同样按外部默认值计。为避免同一纯度同时存在“有标签 / 无标签”两种数据（AE2 中会多占一个类型），本模组的所有产出路径都必须写入 `Purity`：机器配方、工作台配方结果、战利品表、他模组机器的联动产出。数据生成阶段检查此项。
- K0 物料没有档位，外部物品与缺标签时取物料数据中的 `source_purity`；没有则不带纯度。

外部纯度规则：数据包文件 `data/<命名空间>/foodindustrial/purity_rules/<名称>.json`，服务器启动与 `/reload` 时加载，并同步到客户端（JEI 显示与服务端判定一致）。格式（2026-11-04 定）：

```json
{
  "items": ["#c:dusts/salt", "othermod:sea_salt"],
  "fluids": ["#c:brine"],
  "purity": "crude"
}
```

| 字段 | 说明 |
| --- | --- |
| `items` | 可省略。物品标签（`#` 开头）或物品 ID 的列表 |
| `fluids` | 可省略。流体标签或流体 ID 的列表 |
| `purity` | 百分数，或档位名：`crude` / `refined` / `food` / `lab` 取该物料这一档的下限，`poor` 取外部默认值 |

- 只作用于原版与他模组的物品和流体；本模组物品与流体不受影响。
- 写档位名时按命中物品所属物料的界限换算；查不到物料（物品不在任何物料标签里）时记警告，这一项忽略。
- 命中的物品或流体只属于不带纯度的物料（第 1.1 节）时，规则记警告并忽略，它仍不带纯度（2026-11-05，I29）。
- 同一物品被多条规则命中时取最低值；没有规则命中时取外部默认值。
- 加载器不限制数值；本模组自带的规则在数据生成时检查，不得高于该物料的粗制下限；整合包作者自写的规则不设上限（2026-11-04 定）。目前不自带规则，各联动的规则随 I25、I26 添加（2026-11-04 定）。
- 不存在的物品或流体 ID 记警告后忽略；格式错误的文件记错误后整份跳过。

## 2 配方中的纯度规则

### 2.1 计算流程

每次配方完成，按下列顺序计算每个带纯度的产物：

1. **起点纯度**：参与计算的输入按数量**加权平均**（物品按个数，流体按 mB，1 个物品折合 1,000 mB）。默认参与的是 K1–K12 类别的输入；K0 原料与中间物只在配方用 `purity_sources` 指定时参与；不带纯度的原料不参与。外部物品按第 1.6 节取值后参与。
2. **按工序方式计算**（每个产物在 `purity` 中写一个方式，副产物可与主产物不同）：

| 方式 | 写法 | 计算 | 用于 |
| --- | --- | --- | --- |
| 来源 | `{ "mode": "source", "value": 90 }` | 产物纯度 = 写定值（不看输入） | 从不带纯度的原料第一次得到物料：晒盐、烧灰、压榨、割取、浸提、发酵 |
| 除杂 | `{ "mode": "removal", "value": 50 }` | 杂质按质量去掉这一比例（e = 50%）：产物纯度 = p ÷ (p + (1 − p) × (1 − e))，p 为起点纯度 | 结晶、重结晶、过滤、吸附、蒸馏、萃取、离子交换、凝固、蒸发浓缩、反应 |
| 保持 | `{ "mode": "keep" }` | 产物纯度 = 起点纯度 | 研磨、成型、搬运类工序 |
| 劣化 | `{ "mode": "degrade", "value": 10 }` | 目标物按质量损失这一比例：产物纯度 = p × (1 − 10%) | 过热、受潮、氧化等使目标物减少的工序 |

   - 配方不写 `purity` 时：没有参与计算的输入 → 来源方式；有 → 按配方类型的默认方式（../machines/01 第 1.1 节）。
   - 来源方式不写 `value` 时，取产物物料数据中的 `source_purity`；物料也没写时，取该物料粗制档的下限；K0 物料两者都没有时，产物不带纯度。

3. **设备档次加成**（只对来源、除杂两种方式）：执行设备比这条配方的**基准档次**每高一档，剩余杂质再按质量去掉 25%：上式中的杂质项再乘以 0.75^Δ，Δ = 设备档次 − 基准档次；来源方式同样以写定值为 p 计算。基准档次 = 能执行这条配方的设备中最低的档次（配方重载时计算）。保持、劣化方式不加成。
4. **上限**：`"max": 97` 对所有设备生效；`"t0_max": "refined"` 只在 T0 设备（手工工具、被动设备、营火、熔炉、烟熏炉）上生效，写档位名时取该物料这一档的下限，也可写百分数。结果不超过上限，但不低于起点纯度。手工精制配方都写 `t0_max`，按现实工艺逐条给出，多数取粗制或精制下限（07，2026-11-05 定）。
5. **取整**：结果向下取整到刻度（第 1.2 节）。
6. **规范化**（2026-11-05）：执行设备装有规范化模块（../machines/01 第 1.2 节）时，每个带纯度的产物改为它所在档位的下限（按该物料的界限，写定值向上取整到刻度）。只降低或保持，不提高；劣质产物、K0 物料不变。例：化学品 A 食品级 50%–65%，两条工艺得 55%、60%，装模块后都输出 50%。

例：配方“海盐重结晶”去除比例 50%，基准档次 T0（H03 锅）；海盐按“氯化钠”的覆盖分档（粗制 90%、精制 95%、食品级 97%）。

| 设备 | Δ | 4 份 83% 海盐 → 2 份 | 档位 |
| --- | --- | --- | --- |
| H03 锅（T0） | 0 | 90.6% | 粗制 |
| M09 结晶槽（T1） | 1 | 92.6% | 粗制 |
| M15 蒸发结晶器（T2） | 2 | 94.3% | 粗制 |

这条配方写 `t0_max: "refined"`。在 H03 锅上反复执行：83% → 90.6% → 94.7% → 95.2%（精制，到上限），再做只减量；95.2% 的海盐在 M15 上再做一次得 98.4%（食品级）。

### 2.2 其他规则

1. **输入门槛**：有门槛的原料写成纯度原料（第 4 节），按“≥”判定；普通原料不限纯度。
2. **结果唯一**：同一配方、同一设备、同一输入纯度，结果唯一。输入纯度不同则输出不同，所以 AE2 链式自动化时，上游产出的纯度就是下游样板的输入（第 6 节）。
3. **均质（M21 调配机）**：同种物料不同纯度混合，按数量加权平均（向下取整）。
4. **储罐合并**：本模组储罐接收同种流体时按 mB 加权合并纯度（向下取整）；他模组储罐按其自身规则，不同纯度的流体可能不合并。
5. **随机**：只有特殊材料红曲米（M06 曲房）保留随机，配方写 `"purity_range": [40, 73]`（百分数，两端都按写定值向上取整），结果在区间内的刻度值中均匀抽取。
6. **环境只影响耗时和产量**：日照、天气、群系温度改变完成时间或产量，不改变纯度。条件不对时工序不进行，或按配方产出另一物品（例：糖色加热过久得“焦糖渣”）。
7. **规范化不影响门槛判定**：档位名门槛取该档下限，规范化后的产物仍满足同一档的门槛；百分数门槛高于档位下限时可能不再满足，写配方时优先用档位名。M21 均质配方在装了模块的调配机上执行，可把库存中同一档的多种纯度统一成档位下限。
8. **食品门槛**：成品配方默认要求添加剂达到其物料的食品级；是否允许用低档添加剂做“土法食品”留到成品效果设计时决定（11）。

### 2.3 设备档次的取值

| 设备 | 档次 |
| --- | --- |
| 手工工具、被动设备、世界交互；原版营火、熔炉、烟熏炉 | T0 |
| T1 作坊机器；原版高炉；农夫乐事、机械动力的机器 | T1 |
| T2 机器；热力、通用机械、气动工艺、核电工艺的机器 | T2 |
| T3、T4 机器 | T3、T4 |

他模组的机器执行联动配方时，对方的配方格式写不了纯度规则，产出纯度是生成联动配方时算好的固定值（第 7 节）。

## 3 标签匹配（所有输入）

**规则：配方的每一个输入都按标签匹配，包括原版物品、本模组物品和中间化学品；只有输出写具体物品。** 这样任何模组提供的同种物料都能直接进入本模组的配方，本模组的产物也能进入别人的配方。

| 方向 | 做法 | 例 |
| --- | --- | --- |
| 配方引用 | 只引用本模组命名空间的标签 | `#foodindustrial:materials/kelp`、`#foodindustrial:chemicals/soda_ash` |
| 导入（兼容别人） | 本模组标签包含原版物品 + 各模组通用 `forge:` 标签，全部 `required: false` | `materials/kelp` 包含 `minecraft:kelp`、`#forge:crops/kelp` |
| 导出（被别人兼容） | 本模组物品同时加入通用 `forge:` 标签 | 本模组碳酸钠加入 `#forge:dusts/soda_ash` |
| 流体 | 流体同样用流体标签，配方用流体原料 `foodindustrial:fluid` 引用（第 4.2 节） | `#foodindustrial:sulfuric_acid` 包含 `#forge:sulfuric_acid` |
| 催化剂、菌种、工具 | 也用标签 | `#foodindustrial:catalysts/nickel`、`#foodindustrial:cultures/acetobacter` |
| 联动配方 | 往他模组配方类型里注册的配方，输入同样写本模组标签 | 机械动力研磨配方输入 `#foodindustrial:materials/kelp` |

标签的完整清单与默认内容见 08。

## 4 纯度原料类型（Ingredient）

纯度门槛不写成配方的额外字段，而是做成新的原料类型：**配方里哪个原料有门槛，就把它写成纯度原料**。本模组所有机器配方、工作台配方都只认这一写法；因为它注册在 Forge 的原料类型表里，其他模组凡是用标准 `Ingredient` 读配方的，不依赖本模组代码也能直接使用。

### 4.1 物品：`foodindustrial:purity`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `type` | 固定 `foodindustrial:purity` | — |
| `base` | 任意原料 JSON | 被包装的原料，通常是标签：`{ "tag": "foodindustrial:chemicals/soda_ash" }`；也可是物品、列表或其他模组的原料类型 |
| `min_purity` | 档位名或百分数 | `crude` / `refined` / `food` / `lab`（取该物料这一档的下限），或 0–100 的百分数 |
| `material` | 物料 ID，可省略 | 门槛写档位名时用它查界限（第 1.4、1.5 节）；省略时由 `base` 的标签在物料数据中查出 |

判定：物品满足 `base`，且其纯度 ≥ 门槛。门槛在配方加载时换算成 b（向上取整，第 1.2 节）；写档位名却查不到物料，或该物料没有这一档，加载报错。纯度取法：带 `Purity` 的取标签值；不带的（原版、他模组物品，以及缺标签的本模组物品）按外部规则取值，没有规则命中时取外部默认值（第 1.6 节）。

```json
{
  "type": "foodindustrial:purity",
  "base": { "tag": "foodindustrial:chemicals/soda_ash" },
  "min_purity": "refined"
}
```

### 4.2 流体：`foodindustrial:fluid`

Forge 1.20.1 没有通用的流体原料类型，本模组自带一个，同样放进 API 供他模组使用；迁到 1.21 时改为包装 NeoForge 的 `FluidIngredient`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `type` | 固定 `foodindustrial:fluid` | — |
| `tag` 或 `fluid` | 流体标签或流体 ID | 按 08 的规则用标签 |
| `amount` | 整数，mB | — |
| `min_purity` | 档位名或百分数，可省略 | 省略表示不限；K0 原料与中间物只能写百分数 |
| `material` | 物料 ID，可省略 | 同第 4.1 节 |

### 4.3 配方 JSON 示例

物品数量 `count` 写在原料外层，流体数量 `amount` 写在流体原料内部；没有门槛的原料直接写普通标签原料。带纯度的产物写 `purity` 规则（第 2.1 节），不写则用配方类型的默认规则（../machines/01 第 1.1 节）；设备档次加成由框架计算，不写进配方。

海水晒盐：海水与苦卤不带纯度，海盐按来源方式取值（数值依据见 07）。

```json
{
  "type": "foodindustrial:crystallizing",
  "inputs": [ { "fluid": { "type": "foodindustrial:fluid", "tag": "foodindustrial:seawater", "amount": 1000 } } ],
  "outputs": [
    { "item": "foodindustrial:salt", "count": 1, "purity": { "mode": "source", "value": 83 } },
    { "fluid": "foodindustrial:bittern", "amount": 50 }
  ],
  "requirements": { "environment": [ "open_sky", "clear_weather" ] },
  "manual": { "actions": 1 }
}
```

海盐重结晶：起点纯度只取海盐（水不带纯度），去除 50% 的杂质，结果见第 2.1 节的例子。

```json
{
  "type": "foodindustrial:crystallizing",
  "mode": "cooling",
  "inputs": [
    { "ingredient": { "tag": "foodindustrial:chemicals/salt" }, "count": 4 },
    { "fluid": { "type": "foodindustrial:fluid", "tag": "foodindustrial:water", "amount": 1000 } }
  ],
  "purity_sources": [ 0 ],
  "outputs": [
    { "item": "foodindustrial:salt", "count": 2, "purity": { "mode": "removal", "value": 50, "t0_max": "refined" } }
  ],
  "time": 200,
  "manual": { "actions": 4 }
}
```

`purity_sources` 写输入的序号（从 0 开始）；省略时按第 2.1 节的默认取法。条件写在 `requirements` 中，按文本规范第 5 节的词表分类书写，其余字段见 ../machines/01 第 3.1 节。

工作台配方同样可用。复配产品要求全部组分达到食品级，产物纯度由配方给出：

```json
{
  "type": "minecraft:crafting_shapeless",
  "ingredients": [
    { "type": "foodindustrial:purity", "base": { "tag": "foodindustrial:chemicals/sodium_bicarbonate" }, "min_purity": "food" },
    { "type": "foodindustrial:purity", "base": { "tag": "foodindustrial:chemicals/sodium_acid_pyrophosphate" }, "min_purity": "food" },
    { "type": "foodindustrial:purity", "base": { "tag": "foodindustrial:chemicals/starch" }, "min_purity": "food" }
  ],
  "result": { "item": "foodindustrial:baking_powder", "nbt": "{Purity:20b}" }
}
```

工作台配方的产物写固定的 byte（上例 `20b` 为 85%，K12 的粗制；M21 调配机配出的同一产物为 95.2%，食品级，见 ../machines/01 第 1.1 节 R19），相当于来源方式，不享受档次加成。

### 4.4 实现要点（以 1.20.1 Forge 节点为例）

下表是 1.20.1 节点的做法；1.21.1 与 26.1.2 节点改用 NeoForge 的自定义原料接口和数据组件，由 `platform.recipe`、`platform.purity` 适配，业务层代码不变（../machines/02 第 7 节）。


| 项 | 做法 |
| --- | --- |
| 类 | `PurityIngredient extends AbstractIngredient`；持有被包装的 `Ingredient` 与最低 byte |
| 注册 | 在配方序列化器的 `RegisterEvent` 中调用 `CraftingHelper.register(new ResourceLocation("foodindustrial", "purity"), Serializer.INSTANCE)` |
| `test(ItemStack)` | `base.test(stack) && PurityAPI.getPurity(stack) >= min` |
| `getItems()` | 本模组物品：返回门槛值，以及高于门槛的各档下限（低档在前）；外部物品：门槛不高于**含外部规则的有效纯度**（第 1.6 节）时才返回（2026-11-12 按实装改，原写“外部默认值”，11 问题 43）；结果缓存，标签重载时失效 |
| `isSimple()` | 返回 `false`（判定依赖 NBT，原版的快速匹配路径不能用） |
| `isEmpty()` | 委托给 `base.isEmpty()`。`AbstractIngredient` 无参构造时 `values` 为空，默认实现会返回 true，农夫乐事厨锅等按 `!isEmpty()` 过滤原料的序列化器会把纯度原料丢掉（实现时对照 Forge 与农夫乐事源码确认） |
| 缓存失效 | 覆盖 `invalidate()`，清空 `getItems()` 缓存；Forge 在标签重载时调用 |
| 网络同步 | 序列化器实现 `parse` / `write(FriendlyByteBuf)`，写入被包装原料和门槛 |
| 纯度数据 | 物料类别、档位界限、覆盖、来源纯度（第 4.7 节）与外部纯度规则（第 1.6 节）由数据包加载，需同步到客户端，保证 JEI 显示与服务端判定一致 |
| 流体原料 | `FluidPurityIngredient`：`test(FluidStack)`、`getFluids()`、`amount`；同样有 JSON 与网络序列化 |

各节点的 JSON 写法（2026-11-04 实测）：1.20.1 与 1.21.1 节点同第 4.1 节，`"type": "foodindustrial:purity"`，`base` 写对象（`{ "tag": … }`、`{ "item": … }`）；26.1.2 节点 NeoForge 自定义原料的类型键为 `"neoforge:ingredient_type"`，`base` 按原版 1.21.2 起的写法写物品 ID、`#标签` 字符串或列表。本模组配方由数据生成按节点编码输出。流体原料 `foodindustrial:fluid` 是本模组自己的类型，三个节点写法相同。

### 4.5 对外 API

API 位于 `com.tonywww.foodindustrial.api` 包，随模组 jar 一起发布，不单独打包；其他模组 `compileOnly` 本模组即可（2026-11-04 定）。按 `CONVENTIONS.md` 第 2 节，API 只使用原版类型与本模组的业务类型，不出现 `FluidStack` 等各节点不同的加载器类型；加载器流体堆与 `FluidAmount` 的互转由 `platform` 提供。

| 接口 | 用途 |
| --- | --- |
| `PurityAPI.getPurity(ItemStack)` / `getPurity(FluidAmount)` | 读纯度 byte，已套用外部物品规则 |
| `PurityAPI.withPurity(stack, grade)` / `withPurity(stack, percent)` | 生成指定纯度的物品或流体；档位取该物料这一档的下限，百分数向上取整 |
| `PurityAPI.gradeOf(stack)` | 按该物料的界限返回档位；K0 与不带纯度的物品返回空 |
| `PurityGrade` 枚举 | 五个档位、颜色、本地化键；界限由物料数据给出，不在枚举里 |
| `PurityScale` | 256 项对照表：byte ↔ 百分数、两种取整、显示截断、除杂与加权平均 |
| `PurityIngredient.of(Ingredient, PurityGrade)` | 在代码中构造纯度原料（数据生成用），返回原版 `Ingredient` |
| `FluidPurityIngredient.of(TagKey<Fluid>, int, PurityGrade)` | 构造流体原料，返回本模组的 `FluidPurityIngredient`（与节点无关） |

### 4.6 在他模组中的表现

| 场景 | 结果 |
| --- | --- |
| 他模组用 `Ingredient.fromJson` 读配方（原版合成、农夫乐事、机械动力等） | 直接支持 `foodindustrial:purity`，无需改动 |
| 他模组用自定义物品原料格式 | 不支持；这类机器只注册无门槛的配方（见 06） |
| 他模组的 JEI 页面 | 显示 `getItems()` 返回的达标物品，纯度行由本模组 Tooltip 显示；“需要纯度 ≥ …”文字只在本模组的 JEI 类别中出现 |
| AE2 合成样板（允许替代） | 用 `test()` 判定，任何达标物品都可替代 |

### 4.7 纯度数据文件

09 与 08 §C 是物料主表（导出为 `materials.json`，见 09），纯度相关的三项随主表导出：“纯度类别”一栏、来源纯度、单个物料的覆盖。类别界限单独一组文件，整合包可改。

```json
{
  "id": "foodindustrial:salt",
  "category": "foodindustrial:k1_inorganic",
  "source_purity": 83,
  "grades": { "crude": 90, "refined": 95, "food": 97, "lab": 99.8 }
}
```

```json
{
  "id": "foodindustrial:k1_inorganic",
  "grades": { "crude": 90, "refined": 95, "food": 98, "lab": 99.8 }
}
```

- `category` 必填；`grades` 只写要覆盖的档，值写 `null` 表示不适用；`source_purity` 可省略。
- 物料文件放在 `data/foodindustrial/purity_materials/<物料 ID>.json`（2026-11-04 定，I28），由 09 第 D 节与“纯度类别”一栏经数据生成输出。文件 ID 由路径给出，`id` 字段可省略，写了须与路径一致。
- 类别文件四档都写，`null` 表示该类别没有这一档（K0 四档都是 `null`）。类别文件放在 `data/foodindustrial/purity_categories/`，ID：`k0_raw`、`k1_inorganic`、`k2_sugar`、`k3_organic_solid`、`k4_organic_liquid`、`k5_natural_extract`、`k6_colloid`、`k7_fat`、`k8_emulsifier`、`k9_gas`、`k10_synthetic_color`、`k11_culture`、`k12_compound`。
- 加载时检查：每档下限严格递增；小数位数不超过显示规则在该区间的位数（文本规范第 1 节第 6 条）。

## 5 JEI 兼容

| 要求 | 做法 |
| --- | --- |
| 物品与流体能搜索 | 所有物品、流体都注册进 JEI 原料列表；创造物品栏中带纯度的物料按档各列一个：外部默认值（劣质）与各档下限（沿用 2026-11-04 定的“每档一个”），JEI 列表中同一物料只出现一次 |
| 纯度不刷屏 | 不为 `Purity` 注册子类型解释器，JEI 把同一物品的各纯度视为同一原料：列表只出现一次，任一纯度按 R / U 都能查到配方 |
| 每个配方都可见 | 每种配方类型（R01–R19、W01–W02，见 ../machines/01）注册一个类别；能执行它的机器、工具、被动设备都注册为催化剂；配方页列出各设备的耗时、纯度、产率，点选设备图标切换输出槽显示的纯度，转移到 AE2 样板编码终端时按所选设备编码 |
| 世界交互也是配方 | 烧灰、晒盐、硝土生成、冻融、自然接种都做成数据包配方类型，由 JEI 从配方管理器读取，而不是写死在代码里 |
| 标签输入 | 输入槽轮播标签内的所有物品；本模组物品排第一位；槽位 Tooltip 写出标签名，方便整合包作者查 |
| 显示纯度要求 | 槽位 Tooltip 写“需要纯度 ≥ 95%（精制）”；轮播的物品纯度等于门槛；门槛高于外部默认值的槽位不轮播外部物品，不高于时外部物品显示“按劣质计” |
| 显示纯度产出 | 输出槽按“输入纯度取门槛（无门槛取外部默认值）、由所选设备执行”显示结果；纯度行写规则：“来源 83%”“除杂 50%”“保持”“劣化 10%”，有上限时加“最高 97%”或“手工最高 95.2%”；红曲米写“纯度 40%–73%（随机）” |
| 原版设备 | 本模组注册到原版熔炉、烟熏炉、高炉、营火的桥接配方在原版类别中隐藏，只在 R07–R09 类别中显示，原版设备列为催化剂 |
| 显示工艺条件 | 温度、压力、气氛、无菌、环境（群系、露天、天气）、时间、能耗、催化剂 / 菌种，用图标 + Tooltip |
| 概率产出 | 只用于副产物，显示百分比 |
| 多方块 | JEI 展示每台多方块机器怎么搭（2026-11-05 定）：一个“多方块结构”类别，每台一页，画出结构里每个位置放什么方块、哪些位置可换成仓口，并列出所需方块与数量；控制器是这一页的催化剂。展示方式为逐层切换（2026-11-11，用户确认）：平面网格逐层显示方块图标，按钮切层。Patchouli 手册里仍有结构预览（项目已依赖 Patchouli） |
| 原料来源 | 矿物、作物、海水等用 `addIngredientInfo` 写获取方式 |
| 一键转移 | 作坊与机器 GUI 注册自定义 `IRecipeTransferHandler`（JEI 的“+”按钮），逐槽用配方原料的 `test()` 从背包选料。JEI 默认处理器在未注册子类型时只按物品 ID 匹配，会取到不达标的纯度；原版工作台沿用默认转移，取到不达标物品时配方不成立，由玩家手动换料 |
| 联动配方 | 注册进他模组配方类型的配方，自动出现在对方的 JEI 类别中 |

## 6 AE2 兼容

| 约束 | 原因 | 做法 |
| --- | --- | --- |
| 纯度类型数可控 | AE2 以“物品 + NBT”区分存储类型，每个纯度都占一个类型（存储元件有类型上限） | 刻度有 256 个值，但同一条链的结果唯一，每种物料常见 1–3 种；M21 均质能把多种合成一种；装规范化模块的设备只输出档位下限，每种物料最多 4 个档位值（劣质另计） |
| 同一设备、同一输入纯度，产出唯一 | 处理样板按精确物品（含 NBT）匹配输入输出 | 样板绑定具体机器，同一机器、同一配方纯度唯一，上游产出 = 下游输入，链式自动合成成立；产率与 `chance` 按概率多出的产物作为富余收回 |
| 从 JEI 转移的纯度不一定是网络里的纯度 | 转移到样板编码终端时，AE2 取槽位里的那一个：输出为所选设备按门槛输入算出的值，输入为门槛值（无门槛时为不带纯度的物品） | 编码终端支持从网络中拖入实际物品替换；链式样板的输入需换成网络中的实际物品（I24 实测确认，2026-11-11） |
| 标签内有多个模组的同种物料 | 处理样板只认编码时的那一个物品 | M21 调配机提供“归一”配方：标签内任意外部物品 1:1 转为本模组物品，纯度为该外部物品的有效纯度（外部默认值，或外部规则给出的值），玩家可先统一库存再自动化 |
| 合成样板支持替代 | 开启“允许替代”时，AE2 用配方的 `Ingredient` 判断 | 标签 + 纯度 Ingredient 会接受标签内所有满足门槛的物品 |
| 机器能被样板供应器推送 | 供应器一次推送一整套原料（物品 + 流体） | 机器暴露 `IItemHandler`、`IFluidHandler`，有足够的输入缓冲，一次收下整套原料；支持供应器的阻挡模式 |
| 产物能回到网络 | 供应器需要产物回流 | 机器可按面自动输出到相邻容器（含样板供应器、ME 接口） |
| 多方块 | 供应器只能对着方块 | 设独立的输入仓 / 输出仓 / 流体仓方块 |
| 气体 | AE2 原生存储 Forge 流体；通用机械的化学品需要附属模组 | 本模组所有气体都是 Forge 流体 |
| 催化剂、菌种 | 带耐久或 NBT 变化的物品若作为样板输入会导致匹配失败 | 催化剂放独立槽位、不进样板；损耗用机器内部计数（每 N 次消耗一个），不改物品 NBT |
| 随机产出 | 处理样板要求可预期的主产物 | 随机只出现在红曲米，其余产物都按规则计算。M06 曲房的红曲米不进处理样板，产出后经 M21 均质再进入自动化 |
| 无菌发酵的染菌 | 若染菌降低纯度，会破坏样板预期 | 染菌只造成批次减产或报废（退回部分原料），不改变任何产物的纯度 |

## 7 联动模组配方的纯度

他模组的配方格式写不了纯度规则，所以联动配方的产出纯度是固定值：生成联动配方时，取本模组同一配方的纯度规则，输入纯度取门槛（无门槛取外部默认值），按下表的设备档次算好，写进结果 NBT。输入纯度高于门槛时产出不随之提高，高纯物料留在本模组机器上处理。

| 模组 | 设备档次 | 说明 |
| --- | --- | --- |
| 农夫乐事、机械动力 | T1 | 研磨、压榨、洗涤、混合；成品烹饪不带纯度 |
| 热力系列、通用机械、气动工艺、核电工艺 | T2 | 物理分离、结晶、蒸发、精馏 |

化学反应、精制、无菌发酵不注册给他模组机器（06）。每个联动模组在配置文件中有“启用”和“设备档次”两项。
