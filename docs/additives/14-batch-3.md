# 14 第三批：精细合成与专项名单

第三批共 **61 项**（编号 79–139），分七组：合成色素、高倍甜味剂、合成抗氧化剂、酶制剂、营养强化剂、食品用香料、胶基。前三组是附录 A 中的精细有机合成品，后四组对应 GB 2760 引用的专项名单（附录 B、附录 C 表 C.3、GB 14880、GB 1886.359）。本批新增 **14 项工艺**，不新增独立机器：聚合、光化学反应并入 M14 搅拌反应罐，混炼并入 M21 调配机（../machines/01 第 4 节）。石化与煤焦油芳烃链在这里全面展开。

> 营养强化剂的品种、化合物来源以 GB 14880 现行版本为准；本文所列是常用品种，实现前需逐项对照。
