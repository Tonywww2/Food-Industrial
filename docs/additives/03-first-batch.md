# 03 第一批实现的添加剂

第一批共 **30 项**（28 项附录 A 添加剂 + 2 项附录 B 香料；第 24、25 项各含一对同族物质），覆盖 14 个功能类别、全部五个阶段，其中 **20 项在 T0/T1 就有手工或作坊路线**。

## 入选标准

1. **功能覆盖**：酸度调节、膨松、凝固、增稠、着色、防腐、护色、漂白、甜味、乳化、抗氧化、增味、香料，每类至少一项。
2. **原料可得**：主原料来自原版、现有依赖（Farmer's Delight、Thermal、PneumaticCraft），或本模组少量新增原料。
3. **工艺多样**：合起来覆盖全部核心单元操作——发酵、浸提、结晶、煅烧、电解、加氢、精馏、气体吸收等（见 05）。
4. **有历史手工路线**：便于做 T0/T1 玩法，并让同一产品在不同阶段有不同做法。
5. **中间体复用**：葡萄糖、CO2、NaOH、HCl、H2SO4、氧化钙（生石灰）、乙醇、活性炭被多条链共用，减少“一次性”物料。
6. **立刻有用**：能马上用于豆腐、面食、腌肉、果冻、饮料、糕点等食品。

## 暂不进入第一批的理由

| 候选 | 暂缓原因 | 去向 |
| --- | --- | --- |
| 山梨酸钾 | 需要乙烯酮、巴豆醛，石化链比苯甲酸长 | 第二批 |
| 甜菊糖苷 | 工艺只有提取+吸附，与果胶、甜菜红重复 | 第二批 |
| 酒石酸 / 酒石酸氢钾 | 依赖葡萄，原版与现有依赖都没有 | 第二批（葡萄标签） |
| 卡拉胶 | 与琼脂同属红藻胶，等红藻养殖玩法成熟后再做 | 第二批 |
| 合成色素（柠檬黄等） | 需要重氮化–偶合，属精细有机合成 | 第三批 |
| 阿斯巴甜、三氯蔗糖等高倍甜味剂 | 多步有机合成 + 多肽/氯化选择性 | 第三批 |
| 酶制剂、营养强化剂 | 各有独立名单（附录 C.3、GB 14880） | 单独设计 |

后续批次的完整清单见 [11-roadmap.md](11-roadmap.md)。
