# 13 第二批：补齐常用品种

第二批共 **48 项**（编号 31–78），补齐防腐、甜味、增稠、磷酸盐、酸度调节、着色、抗氧化、乳化、增味九类常用品种。它们大多复用第一批的中间体（乙酸、葡萄糖、山梨糖醇、磷酸、碳酸钠、甲苯、发酵与萃取设备），新增 **2 台机器、9 项工艺、约 50 种中间体**。纯度默认值、标签匹配、JEI 与 AE2 规则与第一批相同（见 10）。

| # | 路线 | 阶段 | 流程 | 关键反应 |

| 31 | A 乙烯酮–巴豆醛法 | T3 | 乙酸在裂解炉 700 °C 级脱水得乙烯酮；乙醛碱催化缩合得巴豆醛；二者在路易斯酸催化下生成聚酯 → 酸解 → 山梨酸 → 重结晶 → 氢氧化钾中和 → 造粒 | C2H4O2 → C2H2O + H2O；2 C2H4O → C4H6O + H2O；C2H2O + C4H6O → C6H8O2；C6H8O2 + KOH → C6H7KO2 + H2O |
| 32 | A 丙酸杆菌发酵 | T2 | 乳清或糖液接种丙酸杆菌（瑞士奶酪中的菌）厌氧发酵 → 发酵液加石灰乳 → 浓缩结晶丙酸钙 | 3 C6H12O6 → 4 C3H6O2 + 2 C2H4O2 + 2 CO2 + 2 H2O |
