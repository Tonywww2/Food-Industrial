# 04 机器界面与通用配置

界面布局参考热力系列：主窗口放槽位、储罐和进度，两侧是可折叠的配置面板；侧面输入输出、红石、升级在所有机器上一致。本章规定通用部分，各机器只决定主窗口里放哪些槽位（03）。

界面贴图参考热力的风格，先由脚本生成简单的大色块贴图，以后可整体替换（2026-11-05 定）。

## 1 主窗口

```
┌──────────────────────────────────────────┐
│ 搅拌反应罐                        [模式] │
│┌──┐┌─────────────┐┌──────┐┌────────────┐│
││E ││[I] ┃FI┃┃FI┃ ││  →   ││[O] ┃FO┃┃FO┃││
││  ││[I] ┃  ┃┃  ┃ ││[84%] ││[O] ┃  ┃┃  ┃││
││  ││[I] ┃  ┃┃  ┃ ││ [C]  ││    [排][排]││
│└──┘└─────────────┘└──────┘└────────────┘│
│ 状态：运行中                             │
├──────────────────────────────────────────┤
│              玩家物品栏                  │
└──────────────────────────────────────────┘
 能量区   原料区          加工区   成品区
```

| 元素 | 规则 |
| --- | --- |
| 尺寸 | 宽 176、高 190，所有机器一样（2026-11-05 定）；多方块控制器另有结构页 |
| 分区 | 加工部分从左到右分四个区，每个区用 1 像素线框包住（2026-11-05 定）：能量区（能量条，或燃料火焰与燃料槽）、原料区（物品输入，再是输入储罐）、加工区（从上到下：进度箭头、单独线框里的本次产出纯度、催化剂）、成品区（物品输出，第一个是主产物槽，底色区分；再是输出储罐与下方的排放开关）。没有内容的区不画（无能源的机器没有能量区）；各区线框上下对齐，加工区占用剩余宽度，四个区合起来铺满窗口宽度 |
| 网格对齐 | 元素放在三行的 18 像素网格上（2026-11-05 定）：物品槽相邻不留缝，每列从第一行开始往下排（垂直靠上），水平在区内居中；储罐与能量条占满区的高度，输出储罐给排放开关留出底部；进度箭头在第一行，纯度框在第二行，催化剂在第三行；能量区例外，只放能量条或燃料（火焰与燃料槽上下居中）；放不下时储罐依次变窄（18、16、14、12、10、8，2026-11-11 为 M14 的 6 个输入储罐加 7、6，I31） |
| 槽位排布 | 未单独指定时按上面两条自动排布；各机器可在 I14–I17 另定（2026-11-05） |
| 能源条 | 能量区；FE 机器显示 12 像素宽的能量条，T1 机器显示燃料火焰（悬停显示剩余秒数与温度档）与下方的燃料槽 |
| 储罐 | 竖条，宽 18（放不下时变窄），高 54；输出储罐高 44，下面是排放开关；气体储罐带气体图标；悬停显示流体名、mB / 容量、纯度（格式同 Tooltip 规范） |
| 进度箭头 | 加工区第一行，水平居中；点击打开该机器可做的配方类型的 JEI 页（随 I22） |
| 纯度框 | 箭头下方单独一个线框，写本次产出的纯度百分比（颜色同纯度行），没有产出时为空；悬停显示完整的纯度行（2026-11-05 定） |
| 模式按钮 | 右上角；运行中切换模式时，新模式仍能执行当前配方则保留进度，否则清零 |
| 状态行 | 主窗口底部一行：运行中、等待原料、输出已满、能量不足（T1 写“燃料不足”）、条件不满足（写明哪一条，例“条件不满足：真空”）、红石禁止、结构未成形 |

槽位交互：

- 储罐：手持桶或气瓶点击即装入或取出（装入只进输入储罐）；Shift + 右键排空，需在 2 秒内再点一次确认。
- 排放开关：每个输出储罐下方一个，点击在 无行为 → 排出溢出 → 全部排出 间循环，右键反向（规则见 03 第 4 节，2026-11-05 定）。
- 锁定：输入槽和储罐可锁定为当前物品或流体（含纯度），清空后仍只接受锁定内容。Alt + 单击槽位或储罐：锁定为当前内容，空槽时锁定为鼠标上拿着的物品；再按一次解锁；锁定的槽位画一个小锁（2026-11-05 定）。从 JEI 拖入物品设定锁定随 I22。
- 催化剂槽悬停显示剩余使用次数。
- 槽位与储罐悬停显示类型（2026-11-11 定，用户补充）：空槽只显示类型名，有物品时在物品提示下加一行灰色类型名（与物品名相同时不加）；默认按槽位类别写“输入”“输出”“催化剂”“燃料”“升级”“模块”，储罐写“输入储罐”“输出储罐”；各机器可另起名：M05 发酵缸、M06 曲房、M29 无菌发酵罐的催化剂槽“菌种”，M24 电解槽、M26 电弧炉“电极”，M25 吸附柱“吸附剂”，M31 膜分离机“膜组件”，M30 菌种工作台四个输入槽依次“样本或菌种”“培养基”“供体样本”“表达载体”。仓口窗口同样显示。M30 的四个输入槽按标签限定（2026-11-11，用户补充）：只收 `foodindustrial:culture_bench/samples`、`media`、`donors`、`vectors` 中的物品，手放与自动化都按此判（additives/08 §标签体系）；其他机器的名称只是提示，配方按原料匹配任一输入槽。
- 升级槽、模块槽在升级面板里，每格放 1 个。

## 2 侧面板

面板贴在主窗口两侧，点击图标展开，每侧同时只展开一个；展开状态按机器类型记住，只在本次游戏内有效（2026-11-05 定）。右侧面板收起时的图标：I/O 是设备扳手，红石是红石粉；右侧面板展开后不在右上角画图标（2026-11-05 定）。

| 位置 | 面板 | 内容 |
| --- | --- | --- |
| 左 1 | 信息 | 当前配方、进度（tick 与剩余秒数）、速率倍率、能耗 FE/t、产出纯度、产率、具备的能力（温度、压力、方法） |
| 左 2 | 升级与模块 | 升级槽、模块槽；下方汇总当前加成（速率 ×、能耗 ×、并行数、增加的能力，装规范化模块时显示“规范化”；两类条件同名的词如“真空”只列一次，I15） |
| 右 1 | I/O | 六面配置、自动输入、自动输出（第 3 节）；标题写“I/O”（2026-11-05 定） |
| 右 2 | 红石 | 忽略（默认，红石不影响机器） / 低电平运行 / 高电平运行 / 禁用（2026-11-05 确认默认值）；四个按钮下面只写当前模式名，不显示当前信号（2026-11-05 定） |

T1 机器没有升级面板；没有模式的机器不显示模式按钮。

红石面板与 I/O 面板里的按钮都是 10 × 10 的小按钮（8 × 8 图标），面格 12 × 12；文字按钮高 10，能放下一行字（2026-11-05 定，原为 20 × 20 与 24 × 24）。

## 3 输入输出配置

### 3.1 六面

面板中央是方块的十字展开图，按机器朝向标出前、后、左、右、上、下。每个面分两条通道，面格里上面一个居中的小方块是物品、下面一个是流体，按状态着色（2026-11-05 定）：

| 状态 | 颜色 |
| --- | --- |
| 关闭 | 灰 |
| 输入 | 蓝 |
| 输出 | 橙 |
| 输入 + 输出 | 蓝 + 橙（小方块沿对角线一半蓝、一半橙） |

- 左键按 关闭 → 输入 → 输出 → 输入 + 输出 循环，右键反向，Shift + 左键设为关闭。
- 面格里不写字母，只靠颜色区分；悬停提示写出这个面、物品与流体各自的状态和相邻方块的名称（2026-11-05 定，原为颜色加字母、格内画相邻方块图标）。
- 默认配置：正面关闭；顶面物品输入；底面物品输出；左右流体输入；背面流体输出。能量和进气不受通道限制，任何非关闭面都可输入能量。

### 3.2 高级选项

在某个面上按住 Alt 点击，打开这个面的细分设置（只列出机器有的项）。返回按钮在面板左上角，右边的标题写“高级：前”；下面先是“输出范围”，跟着“物品：”“流体：”两行，每行文字后面是切换范围的按钮（2026-11-05 定）；流体输入范围放在“输入范围”下面一行“流体：”，按同样格式补上（待确认）：

| 选项 | 取值 | 用途 |
| --- | --- | --- |
| 物品输出范围 | 全部 / 仅主产物 / 仅副产物 | 主副产物分别送往不同去处；主产物槽是第一个输出槽（03 第 1 节） |
| 流体输出范围 | 全部 / 指定储罐 | 多个输出罐分开管道 |
| 流体输入范围 | 全部 / 指定储罐 | 指定原料只进某个罐 |

### 3.3 自动输入输出

- 自动输出：物品、流体各一个开关；开启后每批把输出推送到设为“输出”的面上的相邻容器。
- 自动输入：物品、流体各一个开关；开启后每批从设为“输入”的面上的相邻容器拉取配方需要的原料，只拉取锁定内容或能组成当前配方的内容。
- 推送、拉取的频率与退避按 02 第 6 节第 7 条执行。

## 4 设备扳手与红图

机器的输入输出只在界面里配置，不提供在世界里逐面配置的工具（2026-11-05 定）。

| 物品 | 操作 | 结果 |
| --- | --- | --- |
| 设备扳手（Device Wrench） | 右键机器 | 顺时针旋转 90° |
| 设备扳手 | Shift + 右键机器 | 拆下机器；非默认配置保存在物品上，放下时恢复 |
| 红图（Redprint） | Shift + 右键机器 | 记录侧面配置、红石、自动输入输出、模式、锁定 |
| 红图 | 右键同类机器 | 写入以上设置，按目标机器朝向换算面 |
| 红图 | Shift + 右键空气 | 清空红图 |

拆下时机器里的物品掉落，与挖掉相同；只有配置不是默认值才写入物品数据，默认配置的机器物品仍可堆叠，带设置的物品悬停显示“带有设置”。“配置”与红图记录的内容相同（侧面与高级选项、红石、自动输入输出、模式、锁定、排放开关）。配方：设备扳手为 3 铁锭 + 1 铜锭（扳手形）；红图为红石 + 纸 + 地图（无序）（2026-11-05 定，英文名待审）。

## 8 Jade 显示（2026-11-11 定，用户要求）

装有 Jade 时，看向机器或 T0 设备，Jade 框内在名称下方显示（`gui.MachineReadout`，`platform.compat.jade`）：

| 对象 | 内容 |
| --- | --- |
| 机器（含多方块控制器） | 状态行（与界面相同，按好坏着色）；有多个模式时写“模式：X”；条件状态（见下）；曲房写温湿度；无菌发酵罐中途停过时提示可能染菌、上一批染菌时写明；T1 燃料机器写燃料剩余时间，手摇机器写可运行时间；在用的催化剂写剩余次数或“已饱和”；进度条写剩余时间 |
| T0 设备（锅、陶坛、被动设备） | 内容物（物品、流体），条件状态，缺少的条件，每个单元一条进度条（锅写搅拌次数，被动设备写剩余时间） |

条件状态每类一行，只显示该设备能提供、且它的配方里确实要求的值：温度（无时写“常温”）、压力（无时写“常压”）、气氛（机器进气口被挡住时写“进气口被挡住”）、环境（只在露天类模式与被动设备上显示；缺露天时写“不露天”，缺晴天时写“淋雨”）、无菌。物品、流体、能量由 Jade 通过机器的物品、流体、能量能力自行显示，本模组不重复。

Jade 设置里有两个开关：“食品工业：机器状态”“食品工业：锅与被动设备状态”。
