# 04 机器界面与通用配置

界面布局参考热力系列：主窗口放槽位、储罐和进度，两侧是可折叠的配置面板；侧面输入输出、红石、升级在所有机器上一致。本章规定通用部分，各机器只决定主窗口里放哪些槽位（03）。

界面贴图参考热力的风格，先由脚本生成简单的大色块贴图，以后可整体替换（2026-11-05 定）。

## 1 主窗口

```
┌──────────────────────────────────────────┐
│ 蒸发结晶器                        [模式] │
│ ┃E┃  [I]        ┌──┐        [O][O]       │
│ ┃ ┃  [FI][FI]   │→ │ 精制   [FO][FO]     │
│ ┃ ┃             └──┘                     │
│ 状态：运行中                             │
├──────────────────────────────────────────┤
│              玩家物品栏                  │
└──────────────────────────────────────────┘
```

| 元素 | 规则 |
| --- | --- |
| 尺寸 | 宽 176；高按槽位模板取 166 或 190（有储罐或某类槽位一列多于 2 个时取 190）；多方块控制器另有结构页 |
| 槽位排布 | 未单独指定时自动排布：从左到右为能源条或燃料、物品输入、催化剂、输入储罐、进度箭头、物品输出（第一个是主产物槽，底色区分）、输出储罐；放不下时储罐变窄；各机器可在 I14–I17 另定（2026-11-05） |
| 能源条 | 左边缘；FE 机器显示能量，T1 机器显示燃料火焰（悬停显示剩余秒数与温度档）与燃料槽 |
| 储罐 | 18 × 60 竖条，气体储罐带气体图标；悬停显示流体名、mB / 容量、纯度（格式同 Tooltip 规范） |
| 进度箭头 | 中间；旁边显示本次产出的纯度（颜色同纯度行）；点击打开该机器可做的配方类型的 JEI 页（随 I22） |
| 模式按钮 | 右上角；运行中切换模式时，新模式仍能执行当前配方则保留进度，否则清零 |
| 状态行 | 主窗口底部一行：运行中、等待原料、输出已满、能量不足（T1 写“燃料不足”）、条件不满足（写明哪一条，例“条件不满足：真空”）、红石禁止、结构未成形 |

槽位交互：

- 储罐：手持桶或气瓶点击即装入或取出（装入只进输入储罐）；Shift + 右键排空，需在 2 秒内再点一次确认。
- 排放开关：每个输出储罐下方一个，点击在 无行为 → 排出溢出 → 全部排出 间循环，右键反向（规则见 03 第 4 节，2026-11-05 定）。
- 锁定：输入槽和储罐可锁定为当前物品或流体（含纯度），清空后仍只接受锁定内容。Alt + 单击槽位或储罐：锁定为当前内容，空槽时锁定为鼠标上拿着的物品；再按一次解锁；锁定的槽位画一个小锁（2026-11-05 定）。从 JEI 拖入物品设定锁定随 I22。
- 催化剂槽悬停显示剩余使用次数。
- 升级槽、模块槽在升级面板里，每格放 1 个。

## 2 侧面板

面板贴在主窗口两侧，点击图标展开，每侧同时只展开一个；展开状态按机器类型记住，只在本次游戏内有效（2026-11-05 定）。

| 位置 | 面板 | 内容 |
| --- | --- | --- |
| 左 1 | 信息 | 当前配方、进度（tick 与剩余秒数）、速率倍率、能耗 FE/t、产出纯度、产率、具备的能力（温度、压力、方法） |
| 左 2 | 升级与模块 | 升级槽、模块槽；下方汇总当前加成（速率 ×、能耗 ×、并行数、增加的能力） |
| 右 1 | 输入输出 | 六面配置、自动输入、自动输出（第 3 节） |
| 右 2 | 红石 | 忽略（默认，红石不影响机器） / 低电平运行 / 高电平运行 / 禁用（2026-11-05 确认默认值） |

T1 机器没有升级面板；没有模式的机器不显示模式按钮。

## 3 输入输出配置

### 3.1 六面

面板中央是方块的十字展开图，按机器朝向标出前、后、左、右、上、下；每个面显示相邻方块的图标。每个面分两条通道，方格上半是物品、下半是流体：

| 状态 | 颜色 | 字母 |
| --- | --- | --- |
| 关闭 | 灰 | — |
| 输入 | 蓝 | I |
| 输出 | 橙 | O |
| 输入 + 输出 | 蓝 + 橙（通道方格沿对角线一半蓝、一半橙） | IO |

- 左键按 关闭 → 输入 → 输出 → 输入 + 输出 循环，右键反向，Shift + 左键设为关闭。
- 颜色之外同时显示字母，不只靠颜色区分。
- 默认配置：正面关闭；顶面物品输入；底面物品输出；左右流体输入；背面流体输出。能量和进气不受通道限制，任何非关闭面都可输入能量。

### 3.2 高级选项

在某个面上按住 Alt 点击，打开这个面的细分设置（只列出机器有的项）：

| 选项 | 取值 | 用途 |
| --- | --- | --- |
| 物品输出范围 | 全部 / 仅主产物 / 仅副产物 | 主副产物分别送往不同去处；主产物槽是第一个输出槽（03 第 1 节） |
| 流体输出范围 | 全部 / 指定储罐 | 多个输出罐分开管道 |
| 流体输入范围 | 全部 / 指定储罐 | 指定原料只进某个罐 |

### 3.3 自动输入输出

- 自动输出：物品、流体各一个开关；开启后每批把输出推送到设为“输出”的面上的相邻容器。
- 自动输入：物品、流体各一个开关；开启后每批从设为“输入”的面上的相邻容器拉取配方需要的原料，只拉取锁定内容或能组成当前配方的内容。
- 推送、拉取的频率与退避按 02 第 6 节第 7 条执行。

## 4 设备扳手与红图

机器的输入输出只在界面里配置，不提供在世界里逐面配置的工具（2026-11-05 定）。

| 物品 | 操作 | 结果 |
| --- | --- | --- |
| 设备扳手（Device Wrench） | 右键机器 | 顺时针旋转 90° |
| 设备扳手 | Shift + 右键机器 | 拆下机器；非默认配置保存在物品上，放下时恢复 |
| 红图（Redprint） | Shift + 右键机器 | 记录侧面配置、红石、自动输入输出、模式、锁定 |
| 红图 | 右键同类机器 | 写入以上设置，按目标机器朝向换算面 |
| 红图 | Shift + 右键空气 | 清空红图 |

拆下时机器里的物品掉落，与挖掉相同；只有配置不是默认值才写入物品数据，默认配置的机器物品仍可堆叠，带设置的物品悬停显示“带有设置”。“配置”与红图记录的内容相同（侧面与高级选项、红石、自动输入输出、模式、锁定、排放开关）。配方：设备扳手为 3 铁锭 + 1 铜锭（扳手形）；红图为红石 + 纸 + 地图（无序）（2026-11-05 定，英文名待审）。

## 5 多方块

| 界面 | 内容 |
| --- | --- |
| 控制器：主页 | 与单方块相同的主窗口和侧面板（没有六面配置） |
| 控制器：结构页 | 成形状态；未成形时列出缺失或错误的方块坐标与需要的方块，“高亮”按钮在这些位置显示红色粒子 10 秒；已登记的仓口数 |
| 仓口 | 小窗口：所连接的槽位组或储罐（位置同控制器主页）；方向只有输入、输出、关闭，以及自动输出开关；结构未成形时只显示设置 |

## 6 网络与同步

- 配置修改由客户端发出，服务器校验（玩家距离、机器类型、取值范围）后应用并回传。
- 菜单打开期间只同步变化的数值（进度、能量、储罐、状态码）；状态行文字在客户端按状态码查语言键生成。

## 7 文本

界面文字遵循 `docs/text-standard.md`。新增语言键：

| 用途 | 键 | 值示例 |
| --- | --- | --- |
| 面板标题 | `gui.foodindustrial.panel.<info|upgrades|io|redstone>` | 输入输出 |
| 状态行 | `gui.foodindustrial.status.<状态码>` | 输出已满 |
| 条件不满足 | `gui.foodindustrial.status.missing` | 条件不满足：%s |
| 通道状态 | `gui.foodindustrial.io.<off|input|output|both>` | 输入 + 输出 |
| 红石模式 | `gui.foodindustrial.redstone.<ignore|low|high|disabled>` | 高电平运行 |
