# 03 机器的输入输出

本章规定每台机器有哪些物品槽、流体槽和专用槽，以及气体怎么处理。原则：

1. 槽位按**角色**分组，侧面配置、AE2、JEI、界面布局都按角色工作，不按单个槽位。
2. 气体按 Forge 流体处理，不另设气体槽，避免第二套存储和传输体系。
3. 一条配方的输入、输出数量超过某台设备的槽位时，这条配方对该设备不可用（JEI 不列出）；数据生成检查每条配方至少有一台设备能执行。

## 1 槽位角色

| 角色 | 代号 | 自动化 | 说明 |
| --- | --- | --- | --- |
| 物品输入 | I | 可输入，不可输出 | 配方输入 |
| 物品输出 | O | 只输出 | 主产物在前，副产物在后：主产物只进第一个输出槽，副产物进其余输出槽；只有一个输出槽时都进这一格（2026-11-05） |
| 流体输入 | FI | 可输入，不可输出 | 液体或气体 |
| 流体输出 | FO | 只输出 | 液体或气体；气体储罐可开启“满时排放” |
| 催化剂 | C | 可输入，不可输出 | 催化剂、菌种、吸附剂、膜组件、电极、紫外灯管；按机器内部计数消耗，不进 AE2 处理样板 |
| 燃料 | F | 可输入 | 只有 T1 加热类机器；接受原版熔炉能烧的燃料，燃烧时间同原版熔炉；有配方可做时才点燃新燃料，点着后一直烧完（停工也照烧）（2026-11-04 定） |
| 升级 | U | 只能手动 | 速率、能效、并行、规范化（01 第 1.2 节）；T1 0 个、T2 2 个、T3 3 个、T4 4 个 |
| 模块 | X | 只能手动 | 机器专用模块（01 第 4.3 节），只增加能力 |

能源：T1 用燃料（F 槽）或人力、水车；T2 起用 FE，能量从任意未设为“关闭”的面输入。

**空气不是流体。** 需要空气的工艺（通气发酵、燃烧、氧化）由设备的进气能力提供：单方块机器有一个进气面，多方块有进气口方块；进气口被堵住时配方条件不满足。纯氧、氮气、二氧化碳等才是流体。

## 2 容量

| 项 | T1 | T2 | T3 | T4 |
| --- | --- | --- | --- | --- |
| 单个储罐 | 4,000 mB | 8,000 mB | 16,000 mB | 16,000 mB |
| 物品槽 | 64 | 64 | 64 | 64 |
| 能量缓冲 | — | 20,000 FE | 100,000 FE | 200,000 FE |
| 多方块流体仓 | 16,000 mB / 个 | 同左 | 同左 | 同左 |

- 并行升级按并行数放大单次消耗与产出，储罐容量不变；配方单次用量超过储罐容量时，该并行档不可用。
- 储罐可锁定流体种类：清空后仍只接受锁定的流体，防止自动化混入别的流体。

## 4 气体

| 规则 | 做法 |
| --- | --- |
| 存储 | 气体是带“气态”标记的 Forge 流体，单位 mB，与液体共用储罐类；储罐可设为只收液体、只收气体或都收 |
| 范围 | CO2、SO2、SO3、NH3、H2、O2、N2、Cl2、氯化氢、CO、乙烯、乙烯酮、甲烷、环氧乙烷等 |
| 容器 | 气体没有桶，不能放进世界；手动搬运用本模组的气瓶（1,000 mB）。液体与溶液有桶，可倒进世界成为流体方块（2026-11-04 定）。桶装流体带纯度；倒进世界后流体方块不保留纯度，用桶取回时按劣质计（2026-11-04 定），取该物料的外部默认值（additives/10 第 1.6 节） |
| 排放 | 输出储罐下方的排放开关有三档：无行为、排出溢出（产物放不下时排掉储罐里的气体，不阻塞机器）、全部排出（持续排空）；每 tick 最多排 100 mB（每批 400 mB），只对气体，储罐里是液体时不起作用；排放跟随机器的红石设置：设置不允许运行时不排放，默认“忽略”即红石不影响排放（02 第 5 节第 2 步；2026-11-05 定）；排放时冒烟；有毒气体排放的后果见 11 待定问题 5（2026-11-05 定） |
| 联动 | 通用机械的化学品不直接接入（06 第“他模组机器参与”节），只在其流体与化学品转换装置处对接；AE2 按流体存储 |

## 5 辅助方块

部分节点没有提供管道的模组（例如 26.1.2 节点目前只有 JEI 与 Patchouli），流体和气体需要本模组自带的最低限度物流。本模组不做流体管道（2026-11-05 定）：相邻机器之间用自动输入输出直接传递，储罐和气瓶用于存放与手动搬运，远距离用他模组管道。

| 方块 | 阶段 | 内容 |
| --- | --- | --- |
| 木桶罐 | T1 | 4,000 mB，只装液体；开口朝上 |
| 金属储罐 | T2 | 32,000 mB，液体或气体；竖直相连的金属储罐组成一列共用存储，最多 8 层（256,000 mB） |
| 气瓶 | T2 | 物品，1,000 mB，只装气体，不堆叠；可在机器界面、储罐上装入取出 |

储罐规则（木桶罐与金属储罐，2026-11-05 定）：

- 放置后默认不主动输入输出。空手 Shift + 右键切换“自动排出”：每 4 tick 向正下方的容器送出最多 400 mB；再按一次回到默认。不论哪种模式，他模组管道与相邻机器的自动输入输出都可从任意面抽取或注入。
- 方块里画出液面；空手右键在动作栏显示流体、mB / 容量、纯度与模式。
- 手持桶、气瓶等流体容器右键储罐：满容器倒入，空容器取出一容器的量。
- 金属储罐一列只装一种流体：流体从最下层装起、从最上层取出；放上会混入不同流体或超过 8 层的储罐时放置失败。
- 挖掉时流体（含纯度）保存在物品上，放下后恢复；带流体的物品不堆叠，悬停显示流体与数量。一列中挖掉一块，这一块带走它自己装着的部分；断开后上面那一段的流体在这一段里重新从下往上装。
- 物品形态：手持对着空气（准星范围内没有方块、流体或实体）Shift + 右键，在“放置模式”和“使用模式”间切换；对着方块时 Shift + 右键按当前模式正常使用，不切换（2026-11-05 定）。使用模式下像桶一样使用：对流体源方块捞起 1,000 mB（空罐可捞任何流体，有内容时只捞同种，木桶罐不装气体）；对方块的面使用时，若那一面外是空气就放出 1,000 mB；流体方块不保留纯度，捞起时按劣质计（同桶，第 4 节）。
- 配方：木桶罐 = 木板 ×6 + 木台阶 ×1（`P P` / `P P` / `PSP`）；金属储罐 = 铁锭 ×4 + 玻璃 ×4（`IGI` / `G G` / `IGI`）；气瓶 = 铁锭 ×3 + 铜锭 ×1（` C ` / `I I` / ` I `）。

物品搬运用原版漏斗、他模组导管或 AE2。
