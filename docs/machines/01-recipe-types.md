# 01 共用配方类型与机器整合

本章回答两件事：

1. **哪些设备共用配方类型**：手工工具、作坊机器、工业机器只要做的是同一类事，就共用同一配方类型。每条配方只写一次，不同设备执行时速率、产出纯度、产率不同。
2. **哪些机器合并**：功能相近、只在形式上不同的机器合成一台，差异改成“模式”或“模块”。

结果：37 台机器合并为 **29 台**；配方类型从“每台机器、每种工具各有一个”（约 52 个）减为 **19 种通用类型 + 2 种世界交互类型**。原版的营火、熔炉、烟熏炉、高炉也作为 T0、T1 设备执行本模组的干燥、烟熏、窑炉配方（第 5 节）。工艺清单（05 的 P01–P79）不变。

## 1 设备档次参数

配方不再绑定机器。配方只声明“要做什么”和“最低需要什么条件”，设备用 **档次参数（设备档案）** 决定“做得多快、多纯、多少”。

| 参数 | 含义 | 默认取值 |
| --- | --- | --- |
| 档次 | T0–T4 | 由设备定义 |
| 速率 | 进度每 tick 前进的单位数 | T0 手工按操作次数；T1 ×1；T2 ×2；T3 ×4；T4 ×4 |
| 纯度加成 | 比配方的基准档次每高一档，剩余杂质再按质量去掉 25% | 由档次差计算（10 第 2.1 节） |
| 产率 | 物理类配方的主产物（第一个输出）倍率，多出部分按概率产出 | T0–T1 ×1.0；T2 ×1.1；T3 ×1.2；T4 ×1.25 |
| 能耗系数 | 配方能耗（FE/t）× 系数 | T2 ×1；T3 ×1.5；T4 ×2（快的设备耗能多） |
| 能力 | 设备具备的条件 | 温度档、压力档、气氛、无菌、方法（过滤 / 离心 / 离子交换 / 膜等），见第 3 节 |

规则：

1. **纯度由配方的工序规则和输入纯度决定**（来源、除杂、保持、劣化，10 第 2.1 节），设备档次只加成；配方可写 `max` 封顶。配方不写纯度规则时用第 1.1 节的默认规则。
2. **产率只作用于物理类配方**（研磨、压榨、浸提、固液分离、干燥、固态发酵）。化学反应、电解、气相反应按化学计量比书写，产率固定 ×1.0，高档设备只快不多。
3. **产率多出的部分按概率产出，期望值不变**（2026-11-04 定，不用累加器）：每次完成，主产物多出 数量 × (倍率 − 1)，整数部分必出，小数部分按概率多出 1。例：T2 ×1.1，主产物 1 个 → 10% 概率多 1 个；4 个 → 40% 概率多 1 个；流体 250 mB → 固定多 25 mB。AE2 把多出的产物当作富余产物收回。
4. **升级和模块在档案上叠加**：速率升级提高速率和能耗；能效升级降低能耗；并行升级一次处理 N 份。模块只增加能力（如真空、耐腐蚀内衬），不改纯度。
5. **同一设备、同一配方，纯度唯一**。AE2 样板按“这台机器 + 这条配方”编码，因此即使不同设备的纯度不同，链式自动合成也成立；产率与 `chance` 只改变数量。

### 1.1 默认纯度规则

配方不写 `purity` 时：没有参与计算的输入（10 第 2.1 节），用来源方式，取产物物料的 `source_purity`，没有则取该物料的粗制下限；有参与计算的输入，按下表。去除比例是游戏设定，按分离效果分四级：一般 50%、较强 75%、强 90%、纯培养 99%。

| 配方类型 | 默认规则 | 理由 |
| --- | --- | --- |
| R01 研磨 | 保持 | 只改变粒度 |
| R02 压榨 | 除杂 50% | 挤出液相，带走可溶杂质 |
| R03 固液分离 | 除杂 50% | 去除不溶物 |
| R04 浸提与萃取 | 除杂 75% | 选择性溶出目标物 |
| R05 熬煮与蒸发 | 除杂 50% | 去除水分和挥发物 |
| R06 结晶 | 除杂 75% | 晶体析出时排出大部分杂质 |
| R07 干燥 | 除杂 50% | 去除水分 |
| R08 熏蒸与烟熏 | 保持 | 处理食品，不做分离 |
| R09 窑炉 | 除杂 50% | 烧去有机物与挥发分 |
| R10 蒸馏 | 除杂 75%；配方条件要求多馏分时 90% | 精馏分离更彻底 |
| R11 液相反应 | 除杂 50% | — |
| R12 气体吸收 | 除杂 50% | — |
| R13 气相反应 | 除杂 50% | — |
| R14 电解 | 除杂 90% | 电极上选择性析出 |
| R15 吸附与膜分离 | 吸附 75%；配方条件要求离子交换、膜或电渗析时 90% | — |
| R16 液态发酵、R17 固态发酵 | 来源（不看输入） | 产物含量由发酵本身决定 |
| R18 菌种操作 | 除杂 99% | 分离纯培养 |
| R19 配料与混炼 | 复配产物不带纯度；同种物料均质按加权平均 | 10 第 1.1、2.2 节 |
| W01 方块转化、W02 割取 | 来源 | 产物来自世界 |

默认规则按配方本身（类型与条件）决定，不按执行设备区分：同一配方在所有设备上的默认规则相同，设备差异只来自档次加成（2026-11-04 定）。

数据生成时输出一份报表：每种物料在 T0–T4 各档能达到的最高纯度和最早达到食品级的档次，旁边附 03、13、14 中该物料的最早 / 最终阶段，由设计人工对照，报表不自动判定是否一致（2026-11-04 定），不由实装自行调整。

## 3 配方条件与设备能力

配方写“需要什么”，设备写“具备什么”。设备的能力覆盖配方的全部条件时，这条配方才对该设备可用；JEI 只把可用设备列为催化剂。

| 条件 | 取值 | 例 |
| --- | --- | --- |
| 最低档次 | T0–T4 | 深冷空气分离只能 T3 |
| 温度档 | 常温 / 加热 / 高温 / 极高温 / 冷却 / 冷冻 | 热法磷要极高温，只有 M26 |
| 压力档 | 常压 / 加压 / 高压 / 真空 | 加氢要高压，只有 M23 |
| 气氛 | 空气 / 隔绝空气 / 惰性 / 指定气体输入 | 干馏要隔绝空气 |
| 无菌 | 是 / 否 | T4 发酵只有 M29 |
| 方法 | 过滤、离心、沉降、明火、溶剂回收、超临界、真空、耐腐蚀、紫外、聚合、密炼、离子交换、膜、电渗析、多馏分 | 油水分离要离心；焦化要明火（H03 铁锅、M03） |
| 热敏 | 普通 / 热敏 / 极热敏 | 热敏物料只能 M28 或 M17 冷冻干燥模块 |
| 环境 | 露天、天气、群系温度、时间 | 晒盐要露天晴天 |

**同一配方、不同设备的产出差异**，除纯度和产率外，还有两种写法：

- **按档次产出**：输出项带 `min_tier`，低档设备不产这一项。例：蒸馏配方的甲醇馏分写 `min_tier: t3`，M08 蒸馏甑只得到主馏分和残液，M22 精馏塔得到全部馏分。
- **手工参数**：配方的 `manual` 段写手工操作次数；纯度规则与机器相同，写在产物上。没有 `manual` 段的配方不能手工完成。

```json
{
  "type": "foodindustrial:grinding",
  "inputs": [ { "ingredient": { "tag": "foodindustrial:materials/gypsum" }, "count": 1 } ],
  "outputs": [
    { "item": "foodindustrial:gypsum", "count": 1, "purity": { "mode": "source", "value": 80 } }
  ],
  "time": 200,
  "energy": 8,
  "manual": { "actions": 8 }
}
```

同一条配方的执行结果（基准档次 T0；石膏矿石含二水硫酸钙 70%–95%，取 80%，见 07）：

| 设备 | 进度 | 石膏粉纯度 | 石膏粉产量 |
| --- | --- | --- | --- |
| H01 研钵（T0） | 右键 8 次 | 81%（劣质） | 1 |
| M01 石磨（T1） | 200 tick | 84% | 1 |
| M11 粉碎机（T2） | 100 tick | 88% | 1；10% 概率 2 |

### 3.1 配方字段

（2026-11-04 定）

| 字段 | 写法 | 说明 |
| --- | --- | --- |
| `type` | `foodindustrial:<配方类型 ID>` | 第 2 节 |
| `inputs` | 物品 `{ "ingredient": 原料, "count": n }`（`count` 省略为 1）；流体 `{ "fluid": 流体原料 }` | 只引用本模组标签；有门槛的写成纯度原料（10 第 3、4 节） |
| `outputs` | 物品 `{ "item": ID, "count": n }`；流体 `{ "fluid": ID, "amount": mB }`；都可带 `min_tier`、`chance`、`purity` | 第一个输出是主产物；`chance` 写 0–1 的小数，只用于副产物；`purity` 见 10 第 2.1 节 |
| `purity_sources` | 输入序号列表（从 0 开始） | 10 第 2.1 节 |
| `purity_range` | `[下限, 上限]`，百分数 | 只作用于主产物，取代它的纯度规则（10 第 2.2 节第 5 条） |
| `time` | tick，4 的倍数 | 可省略；省略的配方只能由手工设备完成 |
| `energy` | FE/t | 可省略，为 0 |
| `requirements` | 对象，见下 | 可省略；不叫 `conditions`，因为 1.20.1 Forge 把顶层的 `conditions` 当作加载条件数组（2026-11-04 实测、定） |
| `mode` | 机器模式名 | 可省略；执行设备的当前模式须相同，相当于一个条件；模式名随机器加进条件词表 |
| `manual` | `{ "actions": n }` | 可省略；没有这一段的配方不能手工完成 |
| `vanilla_devices` | `campfire`、`furnace`、`smoker`、`blast_furnace` 的列表 | 只用于 R07–R09（第 5 节） |
| `catalyst` | `{ "ingredient": 原料, "runs": n }`；两种（双菌种）时写成列表 | 放在设备催化剂槽（C）；一件够这条配方完成 `runs` 次，省略为 64；到量整件消耗（2026-11-04 定，additives/08 催化剂与助剂） |

条件写在 `requirements` 中，按文本规范第 5 节的条件词表分类书写，值写词表的键：

```json
"requirements": {
  "min_tier": "t3",
  "temperature": "high",
  "pressure": "vacuum",
  "atmosphere": "airtight",
  "sterile": true,
  "methods": [ "centrifuge" ],
  "heat_sensitivity": "sensitive",
  "environment": [ "open_sky", "clear_weather" ]
}
```

- 写出的每个值都是设备必须具备的能力（集合包含），不写表示不限；默认取值（常温、常压、普通）不写。
- `min_tier` 写 `t0`–`t4`。
- 条件键是开放集合：新增条件只在词表与设备能力中登记，不改匹配逻辑（02 第 8 节）。
- 配方类型不另设槽位上限与允许的条件表：一条配方的输入输出数量与条件，至少要有一台登记的设备能满足（03 第 3 节），否则配方重载时报告、数据生成检查报错（2026-11-04 定）。

## 4 机器合并

| 合并后 | 合并前 | 差异改为 | 理由 |
| --- | --- | --- | --- |
| M12 固液分离机 | M12 板框压滤机、M13 离心机 | 滤板组 / 离心转鼓两种模块，可同时装 | 都是固液分离；需要离心的配方只认转鼓 |
| M14 搅拌反应罐 | M14 搅拌反应罐、M36 聚合釜、M37 光化学反应器 | 聚合模式（T3，需低温夹套模块）、紫外灯模块（T4） | 聚合釜和光反应器在工程上都是带附件的反应釜 |
| M15 蒸发结晶器 | M15 蒸发器、M16 结晶器 | 浓缩 / 蒸发结晶 / 冷却结晶 / 等电 / 冷冻五种模式；真空、多效模块 | 路线里“蒸发浓缩 → 结晶”总是相邻，合并后少一次搬运 |
| M17 干燥机 | M17 干燥机、M32 冷冻干燥机 | 冷冻干燥模块（T4） | 同是干燥，只是条件不同 |
| M18 萃取罐 | M18 萃取罐、M34 超临界萃取釜 | 超临界模块（T4，需二氧化碳输入） | 同是萃取 |
| M21 调配机 | M21 调配机、M35 混炼机 | 密炼转子模块（T3） | 同是混合，只是物料黏度不同 |
| M27 气相反应炉 | M27 燃烧炉、M33 管式裂解炉 | 燃烧 / 催化氧化 / 裂解三种模式；炉管段数决定裂解产率 | 都是高温气相反应 |

不合并的机器和理由：

- M03 熬煮灶与 M15、M09 与 M15 等不同档次的同类机器保留，它们共用配方类型，构成升级路径。
- M25 吸附柱与 M31 膜分离机共用 R15，但阶段（T3 / T4）和耗材（吸附剂 / 膜组件）不同，保留两台。
- M26 电弧炉单独保留，它是唯一的极高温设备。
- M19 吸收塔、M24 电解槽、M30 菌种工作台、M06 曲房功能独特，保留。

## 5 原版加工设备

营火、灵魂营火、熔炉、烟熏炉、高炉作为设备执行本模组的 R07 干燥、R08 烟熏、R09 窑炉配方。它们只处理“1 个物品输入 → 1 个物品输出、无流体、无副产物”的配方，条件不超过各自的能力。

| 设备 | 档次 | 配方类型 | 能力 | 耗时 | 产出纯度 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| 营火、灵魂营火 | T0 | R07、R09（只烧灰） | 加热 | 配方时长 × 3 | 按配方规则 | 同时放 4 件，不耗燃料 |
| 熔炉 | T0 | R07、R09（煅烧、焙烧、烧灰） | 高温 | 配方时长 × 1 | 按配方规则 | 燃料同原版 |
| 烟熏炉 | T0 | R07（植物、食品原料）、R08（烟熏） | 加热 | 配方时长 × 0.5 | 按配方规则 | 不做矿物类配方 |
| 高炉 | T1 | R09（矿物、石料的煅烧与焙烧） | 高温 | 配方时长 × 0.5 | 按配方规则，档次 T1 | 不做植物、食品类配方 |

规则：

1. **可用设备由配方声明**：配方的 `vanilla_devices` 列出能用的原版设备。数据生成按配方类型和条件给出默认值：R07 → 营火、熔炉、烟熏炉；R08 烟熏 → 烟熏炉；R09 中温度不超过高温、气氛为空气的配方 → 熔炉，矿物类再加高炉，烧灰类再加营火。干馏（隔绝空气）、熔融、碱熔不进原版设备。
2. **纯度**：按配方的纯度规则计算（10 第 2.1 节）；营火、熔炉、烟熏炉档次 T0，高炉 T1，参与档次加成。
3. **不覆盖原版配方**：同一输入在同一设备上已有原版配方时，保留原版配方，本模组配方不注册到这台设备。例：原木在熔炉中仍烧成木炭，草木灰只能在营火或 M07 土窑上烧；海带在营火上仍先烤成干海带，干海带再在营火上烧成海藻灰。
4. **实现**：配方注册在原版的烹饪配方类型下（熔炼、烟熏、高炉、营火烹饪），由本模组的序列化器从 R07–R09 配方生成；产物纯度在原版设备取结果时按输入纯度和设备档次计算（02 第 3 节）。
5. **JEI**：这些配方在原版的熔炉、烟熏炉、高炉、营火类别中隐藏，只在本模组的 R07–R09 类别中显示，原版设备列为催化剂。
6. **AE2**：原版设备照常接受样板供应器推送；同一设备、同一输入结果唯一。

| 配方 | 规则 | 营火 | 熔炉 | 烟熏炉 | 高炉 | M07 土窑 |
| --- | --- | --- | --- | --- | --- | --- |
| 干海带 → 海藻灰（R09，基准 T0） | 来源 8%（K0） | 8.6% | 8.6% | — | — | 11%（T1） |
| 石膏粉 → 半水硫酸钙（熟石膏）（R09，基准 T0） | 保持 | — | 同输入 | — | 同输入 | 同输入 |
