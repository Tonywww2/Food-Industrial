## A1 AE2 驱动 T1 → T4 整条链

来源：[additives/10 §8](additives/10-purity-jei-ae2.md)，[I24](implementations/I24-ae2.md)。

**目的**：AE2 的处理样板能把一条从 T1 到 T4 的完整生产链自动做完，纯度沿链正确传递，不卡单。

**链**：抗坏血酸，二步发酵法（[additives/04 §28](additives/04-production-routes.md)）：

淀粉 → 液化淀粉液 → 葡萄糖 → 山梨糖醇液（可加离子交换精制）→ 山梨糖醇 → L-山梨糖 → 2-酮-L-古龙酸 → 2-酮-L-古龙酸甲酯 → 抗坏血酸钠 → 抗坏血酸（可加重结晶）

**准备**

- 每个节点所用的设备各一台（各步可选不同档的设备，至少覆盖 T1、T2、T3、T4 各一台），各配一个样板供应器，开阻挡模式
- 原料放进 ME 存储：淀粉、水、氢气、甲醇、硫酸、纯碱等链上要的外部原料，各给足一次下单的量
- 1.20.1：样板从 JEI 转移编码；1.21.1、26.1.2：在编码终端手动放入（AE2 不接 JEI）

**步骤**

1. 逐个节点编码处理样板。从第二步起，在编码终端把输入换成网络里上一步实际产出的物品（纯度与样板产物一致），这是玩家的正常做法（用户决定，2026-11-11）
2. 在终端下单 4 个抗坏血酸
3. 观察合成任务直到完成，期间不手动干预

**通过标准**

- 任务自动完成，ME 存储收到抗坏血酸，纯度与 JEI 中所选设备链的预期相符
- 每一步中间产物在存储里只有一种纯度（同一条链每步一种）；产率多出的产物作为富余留在存储里
- 催化剂不进样板，机器的催化剂槽位不被供应器动到
- 没有一步因为样板产物与实际产出纯度不同而一直等待
