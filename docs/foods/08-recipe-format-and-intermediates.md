# 08 终版配方的写法与食品中间体

成品线工作顺序的第三步（终版配方，[11](../additives/11-roadmap.md) 问题 50）从第 1 批开始。本章先定各批共用的规则与写法（第 1–3 节，2026-11-14 定，11 问题 52），再清点多种成品共用的食品中间体（第 4 节）、与现有物料重叠的成品（第 5 节）、原料缺口（第 6 节）。第 1 批的油脂、甜味料、调味品配方写在下一份文档。

## 1 规则

第 1、3、4、5、6 条于 2026-11-14 定（11 问题 52），第 2 条同日定（11 问题 53），第 7 条见 07 第 9 节。

| # | 规则 | 内容 |
| --- | --- | --- |
| 1 | 步骤数 | 每种成品从已登记的输入（原料、已登记的中间体、其他成品）到成品最多 3–4 步，含灌装封口。只留配料段、主要加工、灌装，其余工序并入相邻一步 |
| 2 | 并入的写法 | 并入的工序不单设配方，由主要工序的配方一并完成：耗时计入，副产物照常产出（如磨浆时滤出豆渣）。合并后的一步要求所有并入工序的条件（取并集）；条件互相冲突、或没有设备同时具备时，分开成两步，因此超出第 1 条上限的允许（2026-11-14，11 问题 56；例：陈醋 5 步）。例：盐水发酵（常温静置）与加热杀菌温度冲突，分两步 |
| 3 | 共用中间体 | 两种以上成品用到、或现实中作为商品流通的中间状态，各自登记物品或流体（第 4 节） |
| 4 | 专属中间状态 | 只用于单个成品的固体用通用的“半成品”物品（第 3 节）；只用于单个成品的液体各自登记流体（带数据的流体在储罐、管道里不能合并） |
| 5 | 液体成品 | 在机器之间以流体流转，灌装封口后成为物品。成品表里登记的是包装好的物品，流体是它的散装形态，ID 与成品相同；配方里两种形态都能用 |
| 6 | 营养数据 | 《中国食物成分表》有对应条目的成品直接取表值；没有的按现实配比从原料计算（01 第 4.2 节）；配比查不到、或按配比算不准（如发酵消耗糖）的，退用 USDA FDC，再退日本食品標準成分表（八訂，2026-11-18 补，11 问题 66），再退商品标签（11 问题 57）；配比计算所需的单项原料数据也可取日本成分表。来源只给范围或下限时取常见商品的典型值；糖醇的能量按各自的值（11 问题 57） |
| 7 | 包装容器 | 随各批成品逐个定，容器种类在各批文档中累加（07 第 9 节问题 10） |

- 规则 1 的“步”按设备上的一次加工计；共用中间体自己的配方不计入用它的成品。
- 规则 3、4 登记的中间体（物品与专属流体）属于物料表，分类为“食品”（2026-11-25 用户定，I47）：`tools/foods/intermediates.json` 写名称、形态、颜色与贴图，`tools/materials/export_materials.py` 把它们接在添加剂物料之后写进 `materials.json`，与添加剂物料同一张表注册、取名与查重。
- 品质只在配料段定（05 第 2 节）。共用中间体若在配料段做成（如肉馅、发面团），带着品质进入下游，下游按 05 第 2 节合并。

## 2 终版配方的写法

每种成品一张配方卡，各批文档按下表填写。

| 栏 | 内容 |
| --- | --- |
| 成品 | 名称、ID、大类；能否食用；能食用的写一份的重量与来源（04 第 5.4 节） |
| 形态 | 物品，或流体 + 包装物品；包装容器；堆叠上限（散装 16、包装 64，01 第 3.2 节） |
| 现实配比 | 各原料的质量比与来源（04 第 6 节）；来源先找国标、行标、文献、专利与厂商资料，找不到的用民间资料（家常菜谱、厂商说明、百科与科普文章等），注明出处（11 问题 60） |
| 营养 | 每 100 g 的能量、蛋白质、脂肪、碳水化合物、膳食纤维、游离糖；注明取表值（食物营养成分查询平台的条目号，11 问题 54）或按配比计算（含加工得率）；液体另写密度 |
| 代谢成分 | 咖啡因、酒精等，每份含量（02） |
| 步骤 | 最多 4 步。每步写配方类型与模式、游戏中的输入输出数量、条件、时长、段（配料或加工）、各档设备（07 第 4 节） |
| 品质 | 评价项（1–4 项）与各项接受的功能类别或品种、可用的协同（04 第 2、3 节）；配料段那一步写 |
| 纯度要求 | 带纯度输入的最低档位（默认食品级，01 第 5 节） |
| 依据 | 配比、工艺、营养数据的来源 |

## 3 半成品

| 项 | 内容 |
| --- | --- |
| 物品 | `foodindustrial:semi_finished`，一个物品 |
| 物品数据 | 目标成品（ID）、阶段（键）；另带 05 第 2 节的品质与标签数据 |
| 名称 | 自动生成“成品名（阶段名）”，如“白面包（生坯）”；阶段名在各批文档中定，进本地化 |
| 纹理 | 按形态分几种（面团、生坯、片、条、粒、块等），颜色按目标成品取；在实装草案中定 |
| 堆叠与食用 | 堆叠 64；不能食用 |
| 配方与显示 | 配方的输入输出按“目标成品 + 阶段”匹配；JEI 按这两项分子类型显示；AE2 样板编码完整的物品数据 |
