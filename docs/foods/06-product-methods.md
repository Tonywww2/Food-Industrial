# 06 成品制作方法（粗略版）与工艺统计

2026-11-14 用户定下成品线的工作顺序（[11](../additives/11-roadmap.md) 问题 50）：先列出全部成品的制作方法（粗略版），统计成品阶段要用的全部工艺，再做机器的基本设计；机器基本设计完成后，设计最终版的成品配方，按配方的需要调整机器；最后整理总结最终的机器设计。本章是第一步。

- **粗略版**：每种成品只写一条主路线（常见的工业或传统做法），只列工序名，不写配比、条件、设备；括号内是该步的说明。家常的简化做法、多条路线、现实依据留到终版配方逐条求证（CONVENTIONS 第 8 节）。
- **范围**：[12](../additives/12-finished-products.md) 的 333 行中，蔗糖、氯化钠是化学品的食品级，泡打粉是化学品 `baking_powder`，路线已在添加剂文档里，本章不列；其余 330 种逐个列出。
- **工序名**：统一用第 1 节的词表，便于第 3 节统计。终版设计时可合并或拆分。

## 2 各大类成品的制作方法


### 01 乳及乳制品

| 成品 | 主要原料 | 工序 |
| --- | --- | --- |
| 酸奶 | 牛奶、乳酸菌 | 高压均质 → 巴氏杀菌 → 液态发酵（接种乳酸菌）→ 灌装封口 |
| 风味酸奶 | 酸奶、果酱 | 调配（酸奶 + 果酱）→ 灌装封口 |
| 果粒酸奶 | 酸奶、浆果 | 调配（酸奶 + 果粒）→ 灌装封口 |
| 酸奶油 | 稀奶油、乳酸菌 | 巴氏杀菌 → 液态发酵 → 灌装封口 |
| 马苏里拉奶酪 | 牛奶、凝乳酶 | 巴氏杀菌 → 凝乳（凝乳酶）→ 固液分离（排乳清）→ 拉伸（热水揉拉）→ 成型 → 腌制（浸盐水） |
| 切达奶酪 | 牛奶、盐 | 巴氏杀菌 → 液态发酵（发酵剂）→ 凝乳 → 固液分离（排乳清）→ 调配（加盐）→ 压榨（压模）→ 陈酿 |
| 奶油奶酪 | 牛奶、稀奶油 | 巴氏杀菌 → 液态发酵 → 固液分离（离心排乳清）→ 高压均质 → 灌装封口 |
| 再制奶酪片 | 奶酪 | 研磨（奶酪粉碎）→ 调配（加乳化盐）→ 乳化（加热熔融）→ 浇注成型（压片冷却）→ 灌装封口 |
| 炼乳 | 牛奶、糖 | 调配（加糖）→ 巴氏杀菌 → 熬煮（真空浓缩）→ 结晶（冷却控制乳糖结晶）→ 灌装封口 |
| 奶粉 | 牛奶 | 高压均质 → 巴氏杀菌 → 熬煮（浓缩）→ 喷雾干燥 → 灌装封口 |
| 调制乳粉 | 奶粉 | 调配（奶粉 + 营养强化剂）→ 灌装封口 |
| 黄油 | 稀奶油 | 巴氏杀菌（稀奶油）→ 搅乳 → 固液分离（排酪乳）→ 调配（加盐）→ 成型 |
| 淡奶油 | 牛奶 | 固液分离（离心分出稀奶油）→ 高压均质 → 超高温灭菌 → 灌装封口 |
| 奶片 | 奶粉、糖 | 调配 → 压片 |
| 双皮奶 | 牛奶、蛋清、糖 | 煮制（牛奶加热结皮）→ 调配（蛋清、糖）→ 蒸制 |
| 姜撞奶 | 牛奶、姜（标签） | 压榨（姜汁）→ 煮制（牛奶加热）→ 凝乳（姜汁冲入） |
| 奶豆腐 | 牛奶 | 液态发酵（酸化）→ 煮制 → 凝乳 → 固液分离 → 成型 → 干燥 |
