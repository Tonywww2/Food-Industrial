## 目标

330 种成品都有每份的营养与代谢数据：能量、饱食度、饱和度、一份重量、七种急性与慢性成分、杂质、维生素与矿物质，按 [I34](I34-nutrition-data.md) 的数据包格式生成；带盐位的成品另有盐分表与亚硝酸盐误用量。

## 范围

- 做：数值输入文件、生成与校验、盐分表、亚硝酸盐误用、酒类的能量与份量、杂质字段、维生素与矿物质字段、覆盖报表
- 不做：数据包格式与加载（[I34](I34-nutrition-data.md)）；代谢结算与效果（[I35](I35-metabolism.md)、[I46](I46-vitamins-and-minerals.md)）；品质与标签的判定（[I39](I39-food-quality.md)）；原版与农夫乐事的数值（[I36](I36-vanilla-nutrition.md)）

## 任务

- [x] 输入文件 `tools/foods/nutrition/batch3.json`–`batch7.json`（第 1、2 批的成品都不能直接食用，没有输入）：每种成品一条，份量、能量、饱食度、卡片的三大营养素、成分来源、游离糖、咖啡因、酒精、亚硝酸盐照各批“能食用成品的数值”一节与卡片录入；字段说明见 [tools/foods/nutrition/README.md](../../tools/foods/nutrition/README.md)
- [x] 能量与饱食度：饱食度按 `round(20 × √(kcal / 2,000))` 生成并与设计值核对；饱和度系数按蛋白质与游离糖的能量占比（4 kcal/g）；能量换算的警告按 17/37/17 kJ/g、酒精 29 kJ/g
- [x] 酒类：每份酒精取卡片的数（酒精度 × 容量 × 0.789），份量按 TTB/NIAAA 标准份；一份的克数按密度（发酵酒与低度混成酒 1.00 g/mL，蒸馏酒按三点拟合式）
- [x] 杂质：“土法”“劣质”的杂质随物品的标签在吃下时加（I35 已做，0.2 与 2 单位），不进每份数据；成品数据的 `impurity` 都为 0
- [x] 维生素与矿物质：按用户定（2026-11-19）取卡片算能量所用的同一条成分表或 FDC 条目，按配料计算的按配料折算并乘 USDA 保留率；来源没有的项留空（不写 0）。28 项都写进 `food_nutrition.json`，游戏现在只读维生素 C、B1、D，其余 25 项等 [I46](I46-vitamins-and-minerals.md) 加入成分键后自动生效（I46 把营养素减为 7 种，文件只留维生素 C、B1、D、A、类胡萝卜素、钙、铁、锌）
- [x] 盐分表：19 种带盐位调味品与精盐的盐分写在 `tools/foods/nutrition.py`，导出到 `food_nutrition.json` 的 `salt`
- [x] 亚硝酸盐误用：82 种成品带误用量（= 卡片的每份加盐量，mg）；只用调味品的 13 种按盐分表重算并核对（差不超过 5%），全部一致
- [x] 生成时校验：缺能量、缺份量、未注册的成品、未知字段、负数、配料核对不符都报错；三大营养素换算差超过 5%、游离糖超过能量给警告（47 条，多为表值能量与 17 kJ/g 计膳食纤维的差）
- [x] 覆盖报表：`build/reports/foodindustrial/food_nutrition.md` 列每种成品的数值、警告、没有数据的成品（65 种不能食用）、各成分键的缺项数与盐分表，并链接 I44 的无来源报表
- [x] `/foodindustrial nutrition show` 与 `missing` 对成品可用（实测 1.20.1）
- [x] 亚硝酸盐的代谢（用户定 2026-11-19 并入 I45，foods/02 §4.4）：成分键 `nitrite_mg`、高铁血红蛋白模型、当日摄入、四档效果、“亚硝酸盐中毒”伤害、显示

## 实现记录

- 用户定（2026-11-19）：维生素与矿物质按卡片的条目查，按配料计算的按配料折算并乘保留率，查不到的留空；游离糖按卡片配比算；27 种成品改用卡片的 ID；亚硝酸盐的代谢并入本计划
- ID：26 种已注册成品改为卡片的 ID（`larou` → `la_rou`、`hot_dog` → `frankfurter`、`jiuniang` → `sweet_rice_wine`、`vanilla_liqueur` → `herbal_liqueur`（名称改草本药酒）、`chinese_ham` → `jinhua_ham`（名称改金华火腿）等），additives/12 与 `foods.json` 一并改，旧占位贴图换名。琼脂果冻保留 `agar_jelly_dessert`（I21 因与化学品“石花菜冻” `agar_jelly` 重名改过），foods/22 第 3.2 节的 ID 随之改
- 工具：`tools/foods/nutrition/fetch_sources.py` 把引用的条目读成每 100 g 的数值写进 `sources.json`（中国食物成分表经食物营养成分查询平台 120 条；FDC 的 SR Legacy、Survey、Foundation 与 Branded 批量文件 93 条；日本食品標準成分表的文部科学省 Excel 9 条；保留率表）；`tools/foods/nutrition.py` 计算、核对并导出 `src/main/resources/foodindustrial/food_nutrition.json` 与报表
- 成分来源：卡片直接用的条目 222 种，按配料折算 36 种，产品标签 2 种，没有来源 5 种（凉皮、肉冻、鱼皮冻、酸梅汤、爆爆珠，全部留空）
- 中国表条目的处理：空白与“—”为没有值（留空），“Tr”为 0；预成型维生素 A 只在胡萝卜素为 0 时取“维生素 A”的值；配料里的糖、盐、油在中国表没有维生素项，用同物的 FDC 条目补（全为 0）
- 游离糖：糖、蜂蜜、糖浆、果汁的糖分（中国表取碳水化合物，FDC 取总糖）占全部原料的份额乘每份重量，蒸发与烘烤失水不计；果酱按来源给的出品；糖果、商品饼干等取条目的总糖；卡片给出数的照卡片
- 游戏里：成品的饱食度与饱和度改由 `FoodNutrition` 按数据给出（取代占位的 4 点与 0.3）；没有数据的成品不能吃；饱食度为 0 的苏打水、气泡水、草本茶饮可在饱腹时喝（`PlatformItems.food` 新增 `alwaysEdible`）；婴儿米粉、蛋白粉、代餐粉按第 7 批卡片改为能吃，调味茶包改为不能直接吃；T0 设备做的苹果干、浆果干也用数据
- 数据生成：`foodindustrial.json` 写出 265 种成品（来源没有的键不写），`basis` 记食物、卡片、来源、加工与假设；数据生成核对饱食度与饱和度系数与算法一致（I39 遗留的检查中属于数值的部分；最低纯度、品质位数目随各批配方检查）
- 营养数据格式（foods/03 §2）新增可选的 `curing_nitrite_mg`、`misuse_nitrite_mg`；`nitrite_mg` 为可选成分（缺省按 0，不计缺键），原版与农夫乐事的手工数据不必补
- 亚硝酸盐：高铁血红蛋白每 1 mg 亚硝酸钠升 0.033 个百分点，封顶 100，半衰期 1.2 h；≥ 10% 发绀（攻击伤害、移动速度 −10%），≥ 30% 缺氧（移动速度改 −30%，攻击速度 −20%，视野变暗），> 50% 失去意识（与酒精共用配置项），≥ 70% 每 1/10 游戏小时受 2 点“亚硝酸盐中毒”伤害（无视护甲）；“体内”面板显示升高值与今日摄入占每日允许量（7.35 mg）的百分比；Tooltip 按物品的护色剂与误用标记显示每份亚硝酸盐与“高铁血红蛋白 +x%”；图标 `gui/metabolism/nitrite.png`
- 实测（2026-11-19，1.20.1）：`nutrition show` 饺子（一份 85 g，误用 +460 mg，缺维生素 C、D）；带误用标记的饺子吃下高铁血红蛋白 +15%（发绀）、面板与 Shift 卡片、Tooltip 正确；设 60% 黑屏失去意识，设 100% 两秒内掉 2 点生命；饱腹时可喝苏打水；`nutrition missing` 列出本模组 168 种（缺维生素 C、B1 或 D）
- 单元测试：亚硝酸盐的升高、半衰期、档位与当日累计（`MetabolismStateTest`）；写出的营养数据保留缺键（`NutritionFileTest`）

## 已确认（2026-11-19 用户批准，原“待审”）

- 维生素与矿物质的留空：来源没有维生素 C 的 111 种、维生素 D 的 167 种、维生素 B1 的 21 种（多为中国表条目，表里没有维生素 D、B6、B12、叶酸等）；`missing` 会一直列出这些成品
- 中国表没有维生素项的纯物质（糖、盐、油）用 FDC 同物补 0；可可粉缺的项用 FDC 169593 补；预成型维生素 A 的取法（胡萝卜素为 0 才取）
- 配料折算选的保留率代码（米饭 0432、猪绞肉煮 1405、面粉蒸煮 0302、牛奶加热 2151、蛋 0107、豆类 0522 等，见各条 `composition_note`）；保留率表没有的营养素按 100%
- 游离糖的拟定：原味酸奶按 0（游戏配方加糖 ×1，现实配比只给“不宜超过 8%”的上限）；风味与果粒酸奶的果料按 10%、果料的糖按果酱 48.5%；冰棍改取表值碳水（按配比算的糖超过卡片能量）；红豆沙按配方 15.5%（不计豆的吸水，偏高）；转化糖浆按 FDC 甘蔗糖浆 73.2%；冬瓜糖按 FDC 蜜饯 80.68%；炼乳按“加糖到约 45%”；中国表条目的糖果、蜜饯、奶糖取碳水全部计为游离糖（偏高）；午餐肉、豆豉鲮鱼罐头、糟蛋按 0；司康、酸菜的配比区间取中值
- 果汁软糖的营养条目是强化维生素 C 的商品，配方不加，维生素 C 按 0；苏打水的无钠版本钠按 0
- 亚硝酸盐：误投亚硝酸钾时也按亚硝酸钠的量计（物品只记“误用”，不分钠盐钾盐，1 mg 亚硝酸钾实为 0.81 mg）；四档的名称（发绀、缺氧、失去意识、亚硝酸盐中毒）；视野变暗为半透明黑色遮罩；当日摄入按身体的游戏日累计
- 卡片待改：红烧肉、东坡肉写的“硬五花 806 号”应为 786（806 是腊肉（生），按 786 计）；速溶咖啡的饱食度 1 应为 2；婴儿米粉、蛋白粉、代餐粉、调味茶包能否食用与 additives/12 开头的旧规定不同，以第 7 批卡片为准
