## 目标

原版与农夫乐事的可吃、可喝物品都有按 [foods/03 §4](../foods/03-nutrition-data.md) 流程配置、经用户确认的营养数据，由数据生成写出、随模组发布（[foods/03 §1](../foods/03-nutrition-data.md)，2026-11-13 定）。

## 范围

- 做：原版（三个节点）；农夫乐事（有农夫乐事的 1.20.1、1.21.1 节点）
- 不做：其他模组（整合包作者或玩家自配）；本模组成品（算法，随成品各批的计划）

## 前提

- I34 完成：`/foodindustrial nutrition missing` 能导出清单，数据生成能读输入、做检查
- 资料：《中国食物成分表 标准版》第 6 版的相关页由用户提供；成分表没有的食物或成分用 USDA FoodData Central（[foods/03 §5](../foods/03-nutrition-data.md) 第 2 条）；加工损失按 USDA 营养素保留率表（同节第 3 条）

## 每一项的通用步骤

1. 在对应节点运行 `/foodindustrial nutrition missing`，按组取物品，一批的数量由用户定
2. 按[流程文件](../foods/agents/food-nutrition-data.md)第 1–9 步执行：对应的现实食物、一份的重量、资料来源、加工方式都经用户确认；AI 执行时在主会话照流程文件做，或用流程文件末尾的 Claude Code 子代理入口
3. 结果写进数据生成的输入（每个模组一份）；同一物品在各节点共用一条数据，只在部分版本存在的物品写 `only_on`（[I34](I34-nutrition-data.md)）
4. 三个节点跑数据生成：检查通过，`nutrition_report.md` 中每项都有来源，与原版饱食度对照无明显矛盾（有矛盾时报给用户，不自行改数）
5. 游戏内抽查：`/foodindustrial nutrition show` 与 Tooltip（[I35](I35-metabolism.md)）显示的数据与输入一致

## 验收

- [x] 原版与农夫乐事在各自节点的 `missing` 清单为空，或只剩用户决定不配的物品（写在本计划末尾，附原因）
- [x] 三个节点的数据生成通过，报表中每一项都有来源

## 实现记录

- 2026-11-13 开始：用户定按组分批（一组一批）；资料为用户能提供的《中国食物成分表》书页，其余用 USDA FoodData Central（经 `fdc.nal.usda.gov` 读取，记 FDC ID 与数据类型）
- 导出三个节点的 `missing` 时发现并修正命令（见 [I34](I34-nutrition-data.md) 实现记录）：修正后原版 44 种（含蛋糕，按一口计；不祥之瓶只在 1.21.1、26.1.2），农夫乐事 84 种（1.20.1、1.21.1 共有 80 种，含三种整块的派按一口计；1.21.1 另有洋葱汤、闪烁沙拉、南瓜派切片与 `debug_pumpkin_pie`）

- 第一批（原版·果蔬，2026-11-13 确认并写入 `tools/nutrition/minecraft.json`）：全部取 USDA SR Legacy 条目与其标准份量（用户指定本批直接用 USDA）；甜浆果参照蔓越莓（一份 100 g，1 cup whole），西瓜片原取 1 wedge 286 g（农夫乐事·4 时改为 50 g，见下），毒马铃薯按马铃薯；干海带一份 14 g，取约 1 米长海带晒干后的重量（桑沟湾海带研究表 3 插值得鲜重约 155 g，表 5 四月鲜干比 11.3），营养按 155 g 鲜海带计，晒干保留率按 USDA 保留率表最接近的 FRUITS,DRIED（维生素 C 20%、硫胺素 70%）；咖啡因、酒精记 0，快吸收糖按完整果蔬不计，维生素 D 取 USDA（均为假定为 0）
- 三个节点数据生成通过，三份生成文件相同；26.1.2 数据生成时物品组件尚未绑定，报表的饱食度、饱和度两列写“–”（原先在此处报错，已改用 `PlatformItems.foodValues(Item)` 判断）。游戏内（1.20.1）抽查：`show` 与 Tooltip 的数值与输入一致；同时修正 Tooltip 组件的位置，原版物品的模组名行带格式代码时也能排在它前面（`GatherComponents` 最低优先级 + 去掉格式代码再比较）

- 第二批（原版·肉，2026-11-13 确认并写入）：牛肉取各零售部位综合（生 169485 / 熟 169486，西冷条目没有维生素 D），猪排取里脊中段带骨排（168238 / 167827），羊肉取各零售部位综合（172545 / 172546），维生素 D 借用羊肉馅（174370 / 172544），鸡肉取整鸡带皮（171447 / 171450），兔肉取家兔综合（172521 / 172522），维生素 D 记 0；一份统一为生 113 g、熟 85 g；腐肉、蜘蛛眼按幻想食物全部记 0，一份 113 g、10 g 为占位
- 杂质（2026-11-13 用户要求）：营养数据新增可选字段 `impurity`（每份杂质单位，默认 0），吃时与成品品级的杂质相加；Tooltip 在快吸收糖后显示杂质（紫灰色，只写数字），`show` 命令与报表也列出。数值由用户定：腐肉、蜘蛛眼、毒马铃薯每份 5，生鸡肉 2，河豚 10（第三批）。游戏内（1.20.1）抽查：吃两份腐肉后杂质 10、进入疲劳档，Tooltip 正常

- 第三批（原版·鱼，2026-11-13 确认并写入）：鳕鱼取大西洋鳕（171955 / 171956），鲑鱼取野生红鲑（173691 / 173692，大西洋野生鲑没有维生素 D），热带鱼参照鲷鱼（173698），河豚参照生鳕鱼并带杂质 10；一份同肉类（生 113 g、熟 85 g）。鲑鱼一份的维生素 D 接近每日需要量
