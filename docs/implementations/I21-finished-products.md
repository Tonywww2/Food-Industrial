## 每一项的通用步骤

1. 物料：按 09 注册物品或流体（I05），名称按文本规范（I04），标签按 08（I06）。
2. 配方：按路线逐条写入数据生成；配方类型与设备按 [machines/01 §2](../machines/01-recipe-types.md)，T0 工序写 `manual.purity`（[additives/10 §2.1](../additives/10-purity-jei-ae2.md)）。
3. 门槛：需要纯度的输入写纯度原料（[additives/10 §4](../additives/10-purity-jei-ae2.md)）。
4. 检查：JEI 可见、最早阶段能做出、化学式与 09 一致。

## 2026-11-12 审定（11 问题 43）

设计侧审完本计划的待审四条（[additives/11 问题 43](../additives/11-roadmap.md)）。照准的：328 个英文名（建议按 text-standard 批量检查后抽查）、大类标签名、`agar_jelly_dessert` 改 ID 与泡打粉改作化学品、占位贴图。要改的：

- [x] 成品先给占位饱食度（[additives/12](../additives/12-finished-products.md) 开头）：能当饭吃的（主食、肉蛋、乳制品、糕点、果蔬制品等）4 点饱食度、0.3 饱和度；饮料与果汁 2 点、0.1；调味料、香精香料类成品保持不能食用。效果设计时整批替换
- [x] 新增两种成品：葡萄汁 `grape_juice`、柑橘汁 `citrus_juice`（[additives/12 §14](../additives/12-finished-products.md)），作为 15 第 226、231 号压榨配方的主产物；成品表 331 → 333 种，物品 328 → 330 个

## 2026-11-12 审定（二）（11 问题 44）

占位饱食度的分法基本照准，补三类不能食用的（[additives/12](../additives/12-finished-products.md) 开头已改）：

- [x] 要烧过才能吃的生面与生坯也不能食用：挂面、米粉、河粉、粉丝、粉条、珍珠粉圆、速冻饺子、速冻汤圆
- [x] 要冲调的三种粉也不能食用：婴儿米粉、蛋白粉、代餐粉
- [x] 其余照准：02（脂肪、油和乳化脂肪制品）、11（甜味料）、12（调味品）三个大类与六种配料成品不能食用；14（饮料类）、15（酒类）与调味茶包 2 点、0.1；其余 4 点、0.3
