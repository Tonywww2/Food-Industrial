## 目标

农夫乐事、机械动力、热力、通用机械、气动工艺、核电工艺的机器能执行对应工序，作物模组经标签接入。

## 范围

- 做：各模组的等价配方注册、开关、节点守卫
- 不做：GTCEu（I26）

## 任务

- [x] 农夫乐事：厨锅、砧板配方；煎锅与炉灶只跑原版营火配方（[additives/06 §他模组机器参与](../additives/06-machines.md)）
- [x] 机械动力：磨石、粉碎轮、搅拌、压制、洗涤、鼓风机（[additives/06 §他模组机器参与](../additives/06-machines.md)）
- [x] 机械动力的应力驱动 M01 石磨、M02 螺旋压榨机（代替水车，2026-11-10 定；本体用手摇柄，见 [I14](I14-machines-t1.md)）：顶面装“传动接口”方块代替手摇柄，接传动轴；32 RPM 等于手摇速度，转速越高越快、最快 ×4；每 RPM 耗 4 应力；只在装了机械动力时注册（2026-11-11，用户确认）
- [x] 机械动力配方使用 `foodindustrial:purity` 时判定正确，客户端与服务端一致（自 I03 移入，[additives/10 §8](../additives/10-purity-jei-ae2.md)）
- [x] 热力、通用机械、气动工艺、核电工艺的对应机器（[additives/06 §他模组机器参与](../additives/06-machines.md)）
- [x] 输出纯度：生成联动配方时按本模组配方的纯度规则、输入取门槛、农夫乐事与机械动力按 T1、其余按 T2 算出固定值；产物不带纯度时不写（2026-11-05，[additives/10 §1.1](../additives/10-purity-jei-ae2.md)）（[additives/10 §7](../additives/10-purity-jei-ae2.md)）

- [x] 每个联动可在配置中关闭；未安装时整文件排除（[CONVENTIONS §2.1](../../CONVENTIONS.md)）

## 实现记录

- 代码：`integration.Integrations`（六个联动的配置“启用”“设备档次”与配方条件）、`integration.ExternalMachine`（他模组机器表：接受的配方类型、能满足的条件、输入输出数量、是否支持概率与纯度原料）、`integration.IntegrationRecipes`（数据生成）、`integration.IntegrationPurityRules`（外部纯度规则）；`platform.recipe.PlatformRecipeConditions`（配方条件 `foodindustrial:integration`）、`platform.compat.integration.PlatformIntegrationFormats`（各模组配方 JSON，按节点写 1.20.1 的 `item`/`nbt` 或 1.21.1 的 `id`/`components`）、`platform.PlatformKinetics` 与 `platform.compat.create`（传动接口）；`PlatformConfig.commonChoice`（选项型配置）
- 生成方式：本模组每条配方对每台他模组机器按 T1–T4 各算一次；机器接受该配方类型、条件全能满足、输入输出数量合规、没有催化剂和培养皿、他模组读不了的流体纯度门槛不出现时才生成。产物纯度 = 输入取门槛（无门槛取外部默认值）、按该档次的设备算出的固定值；结果相同的档次合成一个文件，文件带 `mod_loaded` 和 `foodindustrial:integration`（启用且档次在列）两个条件，改配置后 `/reload` 生效。数据生成写 `build/reports/foodindustrial/integration_report.md`
- 机器与配方数（1.20.1）：机械动力 石磨 9、粉碎轮 9、压制（配盆）8、搅拌（配盆，含加热浓缩）22；热力 磨粉机 10、多驱冲压机 8、离心分离机 8、结晶器 64、精馏塔 24、热解炉 4；通用机械 粉碎机 10、富集仓 10、热力蒸发 3；气动 压力室 5、热气动处理厂 7、热框架冷却 4、精炼厂 5；核电工艺 岩石粉碎机 10、结晶器 6（电解产物是带纯度的流体，核电工艺的流体输出存不了纯度，0 条）。1.21.1 无热力与核电工艺
- 农夫乐事：厨锅只做成品，成品尚无配方；本模组没有切割、去皮类配方，所以暂不生成。煎锅与炉灶用原版营火配方类型，本模组 R07、R09 的营火桥接配方自然可用
- 机械动力：洗涤（鼓风机）无对应配方（本模组没有单独的清洗工序）；鼓风机烟熏就是原版烟熏配方，桥接配方已可用
- 传动接口：只在装了机械动力时注册（1.20.1、1.21.1），方块文件和文本在所有节点生成；顶面接传动轴，每 RPM 4 应力；石磨、压榨机读取上方接口的转速，32 RPM 等于手摇，最快 ×4（`MachineBlockEntity.drivePermille`），转速变化或过载变化时唤醒机器；合成：安山机壳 + 传动轴（无序）；方块模型用机械动力的安山机壳贴图，顶上的半截传动轴由机械动力绘制（Flywheel 视觉与无 Flywheel 时的方块实体渲染器）
- 外部纯度规则：通用机械（盐、硫、氯气、氢气、氯化氢、氧气、二氧化硫、三氧化硫、硫酸）、核电工艺（26 种化学品）、气动（乙醇）按粗制下限计；只收录有粗制档的带纯度物料。规则里未安装模组的条目在加载时静默跳过
- 潘马斯等作物模组：I06 已在物料标签里写入 `#forge:crops/…`（1.21.1 起 `#c:crops/…`）的可选条目，本计划无需改动
- 构建：`deps.opt.<名>` 的可选模组编译时总在、开发运行时按 `-PfiWith=` 加入；可选模组内嵌的模组（机械动力的 Flywheel、Ponder）也进编译类路径；同一内嵌模组出现多个版本时取最高（核电工艺带两个 Flywheel）；机械动力内嵌的 mixinextras-forge 在开发运行时补上 mixinextras-common
- 验证：三个节点编译与数据生成通过。1.21.1 装机械动力与通用机械启动无配方错误：传动接口接创造马达 16 RPM 时应力 64（= 4 × 16），石磨无需手摇即运行，128 RPM 时 200 刻做完 4 件（配方 200 刻，×4）；JEI 中机械动力石磨、粉碎轮与通用机械粉碎机显示本模组配方，产物纯度为 T1 值；机械动力石磨对 `foodindustrial:purity` 原料判定正确（低于门槛的不进料，高于的产出）。1.20.1 装通用机械与核电工艺启动无配方错误，JEI 中热力磨粉机、通用机械粉碎机与富集仓、核电工艺岩石粉碎机显示本模组配方，核电工艺产物显示 T2 纯度；未装各模组时照常启动
- 热力结晶器只认 1–2 个物品 + 1 种流体的配方（`CrystallizerRecipeManager` 跳过不带物品的配方，其 JEI 页读第一个物品输入时越界报错）；原先生成了 6 条只有流体输入的结晶器配方（冷冻薄荷油、冷却卤水等），JEI 加载时报 “Found a broken recipe”，改为至少 1 个物品输入后不再生成（I24 测试中发现，2026-11-11）
- 1.20.1 开发环境启动机械动力（2026-11-11，用户要求）：原先报 `NoClassDefFoundError: net/minecraft/data/DataProvider`，原因是机械动力内嵌的 Registrate（清单写 `FMLModType: GAMELIBRARY`）被当作普通库放在游戏层之外，看不到原版类。构建改为把这类内嵌库也当模组加载、与依赖它的模组一起重映射（见 [CONVENTIONS §6](../../CONVENTIONS.md)）后可启动。另外 Loom 按坐标缓存重映射结果、不随类路径变化重做：在改动之前重映射过的机械动力仍留着 SRG 名（打开创造物品栏时 `NoSuchMethodError: ItemProviderEntry.m_5456_`），删掉该模组的缓存后正常
- 1.20.1 实测（客户端，机械动力 + GTCEu，2026-11-11）：传动接口顶上的半截传动轴由机械动力绘制，接创造马达后石磨无需手摇即运行；JEI 中机械动力粉碎轮、石磨显示本模组配方，产物纯度为 T1 值；创造物品栏正常
- 与他模组自带配方重叠的部分交给他模组（2026-11-11，用户决定：重叠的输入用他模组自己的配方，其余照常生成）：数据生成时读取各联动模组 jar 里的配方与标签（构建把 jar 列表经系统属性 `foodindustrial.externalJars` 传入，`integration.ForeignRecipes`）。同一台机器上他模组的配方若与本模组这条输入数量相同、每个输入都与对方某个输入有交集（标签按 jar 中的标签与本模组的标签展开），就从本模组配方里去掉对方的输入：本模组自己的标签展开成成员逐个比较，剩一个整项时直接写它，否则写加载器的差集原料（`forge:difference` / `neoforge:difference`，“本模组标签减去对方的输入”）；一点不剩时整条不生成；多输入配方无法只去一部分，整条不生成。对方配方带 `mod_loaded` 条件时（如机械动力为热力磷灰石矿写的粉碎配方），本模组生成两份：装有该模组时去掉重叠，未装时保留原样。结果写入数据生成报告。1.20.1：机械动力石磨的碳酸钙整条不生成（方解石、滴水石块都有机械动力自己的配方）；机械动力粉碎轮的氟磷灰石在装有热力时除去热力磷灰石矿；热力磨粉机的氟磷灰石除去 `#forge:gems/apatite`、`#forge:ores/apatite`；通用机械粉碎机的碳酸钙只留方解石；核电工艺岩石粉碎机的碳酸钙只留滴水石块；气动精炼厂的原油蒸馏只留 `#forge:oil`（`#forge:crude_oil` 归气动自己的配方）。1.21.1：机械动力石磨的碳酸钙整条不生成，通用机械粉碎机只留方解石，气动精炼厂只留 `#c:oil`。1.20.1 实测（装机械动力、通用机械、核电工艺与热力，2026-11-11）：加载时没有本模组配方的解析错误；JEI 中热力磨粉机的氟磷灰石输入只有本模组的磷灰石矿与磷灰石粉，机械动力粉碎轮为磷灰石、磷灰石粉、本模组的磷灰石矿与热力的深板岩磷灰石矿（不含热力的磷灰石矿），通用机械粉碎机的碳酸钙只有方解石，核电工艺岩石粉碎机只有滴水石块
