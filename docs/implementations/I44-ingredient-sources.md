## 目标

原先写“暂无来源”的 269 种原料按六类来源规则生成；成品线缺的作物、他模组标签与器官掉落补齐，让七批成品的配方都有原料可用。

## 范围

- 做：六类来源的生成（作物、野生植物、树木、动物与虫、菌藻、矿）、成品线新增作物、接他模组标签的原料、“肢解”附魔与器官掉落、龙涎香与燕根的两条例外、无来源报表
- 不做：金属与类金属（镍、锡、银、铅、粗硒、铬、钴、铂、铑、钯、钒）照问题 4、14 依赖其他模组；菌种的培养配方（[I17](I17-machines-t4.md)）；用到这些原料的成品配方（[I47](I47-food-batch-1.md)–[I53](I53-food-batch-7.md)）

## 任务

### 六类来源

- [x] 作物类：作物方块、生长阶段与掉落，产物即种子（2026-11-19 用户定）；村民交易与村庄战利品（I07 没有现成做法，平台层新增）
- [x] 野生植物类：按群系生成的采集方块，右键或破坏得到产物；食用菌与地衣、苔类同此
- [x] 树木类：树木与树叶、树皮、花、果的采集；树脂与胶乳扩展 H15 割取（W02），按 [additives/07 §H15](../additives/07-manual-crafting.md) 已补的一条
- [x] 同一物种的不同部位共用一个方块或作物，按采集工具、生长阶段或破坏产物区分，不为每个部位单设方块（[additives/08 §C 来源规则](../additives/08-raw-materials.md)）
- [x] 动物与虫类：虫类改为持刀刮取，兽类新增灵猫、河狸两种生物（2026-11-19 用户定）；龙涎香走钓鱼与沉船箱战利品；燕根走崖壁燕巢方块
- [x] 菌藻类：螺旋藻、盐藻、可可毛色二孢并入 M30 的平板分离（样本见实现记录；[I17](I17-machines-t4.md)）
- [x] 矿类：钛铁矿石、软锰矿石、凹凸棒石黏土矿、膨润土矿石、珍珠岩矿石、滑石矿石的矿石生成与分布，按 [I07](I07-worldgen-and-crops.md) 的现成配置
- [x] 外部优先：潘马斯同种作物的标签并入本模组原料标签（核对过的标签名），两边的物品都能用；作物没有世界生成，不设后备开关（[additives/08 §B、§C](../additives/08-raw-materials.md)）
- [x] 具体群系、生长条件、掉落源、村民交易等级与产量逐种列进本计划的生成清单（`tools/world` 的输入文件），按类别的统一规则填默认值，特例单列

- [x] 草本组标签 `materials/herbs` 收 08 已有的药材物料（[foods/21 §1](../foods/21-batch7-beverages.md)）

## 实现记录

- 生成清单在 `tools/world/sources.py`（逐种的部位、群系、交易等级、颜色），导出 `src/main/resources/foodindustrial/world_sources.json` 供启动时注册，并检查 08 §C 写成六类来源的 269 种原料都有且只有一个来源；`--markdown` 写出评审用的 [I44 生成清单](lists/I44-generation-list.md)
- 用户定（2026-11-19）：乔木长成树（树苗 + 自己的树叶，树干借原版原木；皮、木、树脂、胶乳从树干来的 37 种另有自己的原木），灌木与木质藤本做一格的果丛；作物产物即种子；虫类改采集，兽类新增生物
- 规模：作物 76 种（含成品线的糯稻、绿豆、赤豆、黑豆、芥菜、蚕豆、高粱、大麦、啤酒花）、野生草本 45 种、乔木 86 种、灌木 28 种，方块 361 个；新原料物品 19 个（含肢解的猪皮、猪后腿、小肠、鸡爪与粽叶）
- 代码：`world.source` 包（`SourceTable` 读清单，`SourceBlocks` 注册，`SourceHarvest` 采摘规则，`SourceVillages` 交易与战利品，`SourceData` 战利品表、标签、割取配方，`SourceWorldgen` 树与草丛，`SourceTexts` JEI 信息页，`SourceOrgans` 肢解，`SourceAnimals` 生物）；平台层新增 `HarvestPlantBlock`、`FruitLeavesBlock`、`WallNestBlock`、`PlatformAnimals`、`PlatformAnimalRenderers`、`PlatformLoot`、`PlatformTrades`、`PlatformEnchantments`、`PlatformEvents.onLivingDrops`；`ModTags.extra` 让其他代码往物料标签里加内容
- 采摘：生长阶段 0–3；兼采花与果的树种第 2 阶开花（空手采花）、第 3 阶结果（空手采果），只采花的在第 3 阶；剪刀在第 3 阶采叶；采后回到第 0 阶（树叶）或第 1 阶（果丛、草本）。手持方块时不采，便于贴着树叶放方块
- 作物：手持产物右键耕地种下；成熟掉落清单的各部位，未熟掉落一个产物；农民在 2–5 级出售（各级 6/4/3/2/1 个，1–4 绿宝石），村庄房屋箱子按气候各加一个奖池（0–2 组，每组 1–3 个）
- 野生草本：长成后右键采集（可再生），破坏也给产物，剪刀或精准采集连株取下移栽；沙漠、恶地、沙滩的草本也长在沙上
- 树木：树苗长成清单的树（阔叶同橡树、针叶同云杉、棕榈同金合欢的分叉树干），世界生成的树叶年龄随机，有的正开花或结果；树叶照橡树掉树苗与木棍。自有原木：斧去皮掉皮（变成原版去皮原木）；砍下掉木料（精准采集保留原木）；持刀割取树脂（W02，休息 6,000 tick），胶乳与枫糖浆副手拿玻璃瓶
- 原版同种：橡树、深色橡树树叶 2% 掉橡子壳；成熟胡萝卜 25% 掉胡萝卜籽；乌梅为梅子在烟熏炉熏制（R08）；栀子丛加花期（第 2 阶采栀子花）
- 动物与虫：紫胶原胶持刀刮丛林树叶、胭脂虫干刮仙人掌（休息 6,000 tick）；灵猫（豹猫体型，丛林、热带草原）掉灵猫香，河狸（狐狸体型，沼泽、河流）掉海狸香囊，繁殖得同种；龙涎香在钓鱼 1%、沉船宝箱 15%、补给箱 5%；燕巢贴在山地崖壁（Y 64–192），持刀刮燕根（休息 12,000 tick），挖下得燕根
- 菌藻：M30 平板分离的样本新增碱湖（天然碱矿）→ 螺旋藻粉、盐湖（岩盐、苦卤桶）→ 盐藻粉、可可豆 → 可可毛色二孢
- 矿：钛铁矿石、软锰矿石（主世界）；凹凸棒石黏土矿层、膨润土矿层（沙漠与恶地）、珍珠岩矿层、滑石矿层（山地）掉对应矿石物品（精准采集保留方块）。这四个矿层原拟与物品同名，因已有同名化学品物品改加 `_deposit`
- 他模组标签：椰子、核桃、坚果、萝卜、黄瓜、燕麦、甜菜根（含原版甜菜根）、叶菜、生姜、大麦等用潘马斯核对过的标签名（`forge:`/`c:` 的 `crops/<名>`、`nuts` 等）；鸭、鸭蛋、虾、紫菜的标签名未能核对（开发环境没有相关模组）；牛皮接原版皮革与通用皮革标签；草本组 `materials/herbs` 收 13 种药材物料；西瓜、白栎木、蒲公英、食用菌、玫瑰花、冷杉针叶、白柠檬、葡萄柚按 08 写的原版或他模组物品补进标签
- 粽叶：工作台竹子 ×1 → ×2
- 肢解：1.20.1 代码注册（宝藏附魔，附魔台不出，可附剑与斧）；1.21 起为数据附魔，进 `treasure`、`tradeable`、`double_trade_price`、`on_random_loot` 标签

## 待审（实装时拟定，请确认）

- 生成清单的全部数值：作物的成熟掉落与农民等级、村庄气候；草本与树木的群系组和稀有度（树 1/8，沙漠树 1/16，椰子 1/4，果丛 1/32，草本 1/24）；各部位的数量；见 [I44 生成清单](lists/I44-generation-list.md)
- 农民交易：本模组的作物产物加进农民 2–5 级的候选，第 2 级候选从 3 个变成 40 个，原版的南瓜、苹果交易会少见；也可改为只放进 3–5 级，或交给流浪商人
- 种属的处理：变种分开做树（酸橙与玳玳、橘与红橘、依兰与卡南伽、吐鲁香脂与秘鲁香脂）；芥菜籽（黑芥）与芥菜（褐芥）分作两种作物；墨红、胡椒按 08 归作物；梅树结梅子、乌梅由梅子熏制；椰子树结椰子干；橡子壳取原版橡树叶、胡萝卜籽取原版胡萝卜
- 生物：灵猫借豹猫、河狸借狐狸的体型与行为（河狸会像狐狸一样叼东西、睡觉）；刷新权重与群大小（灵猫 4、1–2 只，河狸 6、1–3 只）；没有刷怪蛋
- 肢解：每次击杀都掉齐表中部位（不按概率）
- 燕根：08 定为“崖壁燕巢方块”，但 swallowroot（燕根）本是植物 *Decalepis hamiltonii* 的根，与燕窝无关；现按 08 做成燕巢，若改为野生草本只需改清单
- 龙涎香：钓鱼 1%、沉船宝箱 15%、补给箱 5%
- 矿层的名称与分布：钛铁矿石 0–48、软锰矿石 0–64（主世界），凹凸棒石黏土矿层 40–80、膨润土矿层 32–80（沙漠与恶地），珍珠岩矿层 32–160、滑石矿层 0–96（山地）
- 螺旋藻、盐藻的样本（天然碱矿、岩盐与苦卤桶）；苦卤桶作样本时连桶消耗
- 鸭、鸭蛋、虾、紫菜的他模组标签名（未能核对）
